# 焦点与空间组件审查

已逐项检查五个源任务的指令、验证脚本及相关场景／组件。旧 `highlight` 任务族的分组不忠实：虽然考查技能不同，五个 Web 任务都使用三个悬停目标、优先级文字及 Patrol／Stop 按钮。现在五项均有直接编写的 2.0.0 双语提示词及独立组件契约。

| 任务 | 1.0.0 中移除或弱化的要求 | 旧替换及新增项 | 修订与验收 |
| --- | --- | --- | --- |
| og-web-0014 | 精确标签矩形 (−65, −47, 130, 18)、父节点挂接、提供的控制器和角色引用 | 真实组件接线变成无关的全局 IDLE/PATROL 标签及悬停轮廓；旧版有三物体悬停游戏，新版提供任意控制器状态、调试开关及移动／重置 | 移除无关悬停／优先级要求。提供 UnitAI，只要求构建和绑定标签。使用独立控制器检查控制器／角色／标签引用、精确矩形、随角色移动、状态和可见性。源控制器已处理可见性及初始文字，不要求新建 AI 系统。 |
| og-web-0021 | 可复用标记实例、发现分组、真实宝箱锚点的高优先级、保留 ChestTarget 及继承空间变换 | 锚点变成三个无关优先级标签；旧版有 Patrol／Stop 和悬停控件，新版提供目标选择、父节点／相机移动与重置检查 | 恢复提供的 Point 类，在宝箱局部原点挂接并注册一个高优先级实例。保留已有目标身份与局部 (0, .25, 0)、宝箱高度 1.45、Y 轴旋转 180°。检查精确引用、注册成员、优先级 3、未改动兄弟节点及投影世界坐标。 |
| og-web-0028 | 可复用点类型、枚举、独立 targeted 标志／重置助手、精确三维坐标、相机和注册成员 | 三个空间标记变成等间距悬停框；旧版有 AI 开关，新版提供最高优先级未选目标选择和透视检查 | 恢复三个命名实例及原坐标／优先级，允许 0.05 世界单位误差。保留相机 (0, 1.6, 4)，检查深度投影、父节点／相机变动、独立状态、重置保留变换／优先级、Enemy → Pillar → Gate 顺序及无重复。 |

空间标记渲染器由起始项目提供，将真实变换层级透视投影到 SVG，三个坐标均参与计算。它替代原运行时的场景组装，同时保留场景数据、挂接与发现要求。拾取渲染器为提供的 WebGL 代码，不额外要求求解者编写着色器／渲染器。端到端探针用于观察恢复后的组件契约，不替代核心要求。

五项均通过本地三次重复检查，包括行为变异、渲染故障和起始项目拒绝；黄色拾取物截图也已目视检查。最终哈希绑定证据记录在 `validation/task-audit.json`。不宣称实测难度等价或新的求解者分数。
