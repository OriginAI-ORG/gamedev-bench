# 小地图审查

分别检查了 `og-web-0040`、`og-web-0041`、`og-web-0077` 和 `og-web-0078` 的指令、场景、脚本、验证器及五个图像资源。旧 Web 任务族将四项都替换为通用交互地图，丢失配置与编程的区别、精确图片／布局、按对象身份跟踪标记及不同起始项目的职责边界。

| 任务 | 从旧改编中移除的要求 | 恢复／保留 | 浏览器替换 | 明确新增项与限制 |
| --- | --- | --- | --- | --- |
| og-web-0040 | 求解者实现通用地图移动／缩放，以及资源／图片豁免 | 200×200 根节点、外边距 5 px、内容边距 20 px、64 px 边框切片、原平铺图案、居中箭头、隐藏宝石／感叹号原型；仅配置 | 可编辑 ui.json，五个命名图片描述符，提供 DOM／canvas 渲染器 | 实际像素／布局检查及不可变运行时；替换原生资源编码，解码图像相同 |
| og-web-0041 | 缺少可复用对象生命周期的通用地图 | 首帧布局、玩家引用、初始缩放 1.5 且限制 .5–5、逐分量缩放、对象身份字典、按类型可见克隆、相对投影、朝向 + PI/2、边界标记 .75、滚轮 ±.1、世界分组／事件及移除 | Minimap 类、Map、Set、DOM 图片和 EventTarget；明确世界集成函数 | 明确半开内部边界、所有边界方向、回到内部恢复缩放、同名对象、属性 setter、幂等移除／销毁及监听器清理 |
| og-web-0077 | 为纯界面任务新增小地图逻辑 | 相同 200×200 布局与原图、直接 PNG 绑定；原跟踪／世界逻辑全部提供 | ui.json 使用直接图片路径，提供的交互示例保留移动、朝向、缩放和收集 | 验证已有集成，不要求重写；世界展示是检查视图，不复刻无关原关卡和美术 |
| og-web-0078 | 重建起始项目已有的世界／分组接线 | 提供声明、原型缓存、世界事件、250×250 UI／200×200 网格，以及未完成的初始化／投影／缩放／移除方法 | 提供构造函数和 world.js，仅编辑 Minimap 方法 | 与 og-web-0041 相同的边界／身份／生命周期探针；world.js 不可变；保留 250 px 界面，不统一成 200 px |

四个源压缩包的五张 PNG 哈希完全相同。对于 `og-web-0040/0060`，四张 RGBA 图在原资源文件偏移 409 处逐字节存在；RGB 蓝图图案位于偏移 408。命名浏览器描述符保留资源绑定工作，而不保留原生资源文件。原 128×128 边框使用 64 px 切片，中央源切片宽／高为零。提供的浏览器渲染器对这些退化中间切片采样接缝，保留规定切片且不产生空缝。这是提供的兼容设施，不是新增算法任务。

源验证器检查标记变换、基本缩放方向和直接移除，但未覆盖全部钳制边界、身份冲突、真实滚轮绑定或移除事件路径。修订增加这些探针，拒绝错误朝向、外部缩放、钳制及断开事件／残留条目。界面验收检查原素材哈希、配置、实际几何、重复图案像素及已有实时集成。小数布局可能使截图裁剪偏移一像素，因此图像探针使用纯色内部及重复图案线，避开脆弱的颜色边界。

两个 UI 任务保留无代码约束，只编辑 ui.json；逻辑任务保留不同起点。这保留核心工作，但不声称 JSON 编辑与原生场景编辑的操作或用时相同。未重跑模型难度基线。

四项均通过参考实现三次重复、定向变异、视觉故障和起始项目拒绝检查。最终批次证据按稳定共享文件及元数据记录于 `validation/task-audit.json`。
