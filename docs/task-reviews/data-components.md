Asset substitutions for og-web-0016: supplied original local SVG shield/heart images replace the two source bitmaps, and a shared CSS 8 px monospace theme replaces the source font/theme bundle. For og-web-0032, a directly authored potion SVG replaces the provided item bitmap. For og-web-0033, a local 128×128 SVG star replaces the source 346×324 PNG while keeping .58 sprite scaling and the explicitly required 72×72 hit area. The source bitmap dimensions and collision rectangle do not imply a shared bounding box; collision and visual scale are tested separately. Loading, composition, resource binding and layout obligations remain; glyphs and art are not claimed identical. These substitutions are recorded here rather than inserted as disclaimers into solver prompts.

QA: all eight passed three-repeat local QA, behavioral mutations, visual faults and starter rejection. The FSM actor-binding mutation was changed from a crashing null actor to a runnable wrong actor, so its rejection establishes identity checking rather than crash detection. The stats heart asset path was corrected before its passing run. The draggable scale mutation exposed an entry-page routing gap in the QA harness; `/` now receives mutations targeting `index.html`, and the complete task passed after that fix. The damage cleanup probe now tolerates a removed label just like its supplied controller, detecting stale subscriptions through extra calls rather than a null-label crash. Final evidence is recorded against the current shared files in validation/task-audit.json.
