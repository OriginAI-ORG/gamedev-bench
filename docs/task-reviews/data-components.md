# 可复用数据与生命周期组件

各条目将原始指令、验证器及提供的组件／主题文件，与旧 Web 提示词和任务族实现逐一比较。这些是组件练习；2.0.0 起始项目提供展示和输入，避免无关玩法替代组件要求。

| 任务 | 1.0.0 中移除或弱化的要求 | 旧替换与额外要求 | 修订与独立验收 |
| --- | --- | --- | --- |
| og-web-0015 | Card 类型、对象身份、可复用牌堆 API、修改后的数量通知、任意卡牌 ID／费用及真实随机洗牌 | 卡牌对象和资源方法变成 A/B/C/D 界面字符串与计数；新增固定种子展示、重置和列表界面 | 恢复 CardPile、提供的 Card 对象及 EventTarget 通知。检查从队首移除、返回引用身份、每次变更的数量、空抽、清空、从 1 开始的列表、重复对象出现次数及独立数组。可注入的 Fisher–Yates 用于确定性浏览器检查；具体算法是新增明确要求，原实现委托运行时洗牌。TypeError 替代原有类型数组约束，展示与种子由起始项目提供。 |
| og-web-0020 | State(actor) 引用、可复用 State／FSM、真实生命周期调用及外部通知载荷 | 通用组件转换变成硬编码状态标签与日志；新增三种姿态、重置和重复同状态测试 | 恢复 State 与 FiniteStateMachine 模块。独立实例化任意子类，检查 actor 身份、首次转换不退出、旧状态退出先于新状态进入、通知前赋值、精确事件载荷和独立状态机。提供的姿态示例使用组件，仅有日志不能通过。重复状态行为明确公开，不能藏在验收中。 |
| og-web-0016 | 约 90×16 的居中布局、共享 8 px 主题、独立加载图片、组间距 0/2、文本双轴对齐和可复用更新 API | 有纹理主题的界面变成通用图标／文本计数；新增与源 UI 无关的伤害／格挡／治疗规则和初始值 5/30 | 移除额外战斗算法，提供直接数值控件。恢复 StatsUI.updateStats、原测试的 4/10 数据、整组隐藏／恢复、精确间距、等比图标、共享主题和视口居中。检查任意直接更新、真实输入、加载像素、销毁和重置。 |
| og-web-0032 | 物品资源身份、导出物品数组、缓存的网格／Slot 引用、setItem／setDataEmpty 调用和随机数量 | 资源背包变成 DOM 槽位文字与计数；新增六格容量、点击移除形成空位及重置 | 提供 Item／Slot 类，恢复 Inventory.addItemResource／clearAllInventoryItems。检查数组与槽位引用完全相同、每次添加新对象、选择首个空格、随机端点 1 和 20、满背包不消耗随机数、原地清空数组及调用每个 Slot。空位移除仍是已提供行为。检查真实图标像素和可见数量。 |
| og-web-0030 | 可配置特性对象／名称／图标、完整阈值 2/4/6、资源格式化输出和只突出最高达到档位 | 资源面板变成硬编码精灵数量和单阈值 2；新增单位控件、移除与重置 | 保留提供的结构，恢复 TraitUI.traitData／active／update。提供的 Trait 辅助类保留精确对象身份和不同名称计数。检查任意特性／格式化回调、图标替换、三个阈值、最高激活档、直接赋值 active、重复／不匹配单位及移除。BBCode 替换成由 span 渲染的文字／颜色标记；本地 SVG 替代位图，原数据和阈值保留。 |
| og-web-0031 | 单位事件接线／分组发现、动态价值方法、精确返回的属性资源、每帧精灵朝向 | 资源感知出售变成固定价格卡牌和返回名称列表；新增键盘快速出售与重置 | 恢复重叠、放下和快速出售事件订阅、计算价格、向 UnitPool 传递精确属性引用及移除单位。保留提供的渲染／高亮辅助器供集成。任意 2/3/5 价格改回 Swift Rogue 3×1 和 Stone Champion 4×3。检查错误单位事件、重复设置／出售、双向朝向、离开、销毁及真实指针／键盘。 |
| og-web-0033 | 初始位置／缩放捕获、可复用组件、生成／销毁补间、平滑跟随、层掩码、带真实重叠目标引用的放下事件 | 区域重叠变成指针中心包含；缩小移除变成立即消失；新增取消与重置 | 恢复 Draggable、初始值独立副本、72×72 碰撞区域、精灵缩放 .58、掩码 2、阻尼 20 和真实 dropped 载荷。保留位置 (512,360)、(512,180) 及 120×48 DropTarget。浏览器明确采用指数阻尼和 160 ms 动画，这是新增时间细节，同时保留连续运动及原测试 200 ms 内移除要求。检查中间缩放、帧拆分不变性、边缘重叠、过滤干扰对象、取消和清理。 |
| og-web-0025 | Player 到控制器的真实订阅、提供的累加器引用和独立 HUD 挂接 | 事件集成变成点击角色计数；新增生命值 100、失败锁定、闪烁／重置 | 移除无关生命／失败要求，原任务持续累加发出的伤害。提供现有 Player 和累加处理器，只要求 HUD 创建／绑定／订阅。检查精确标签引用、外部事件、任意数值、七次各 20 伤害、世界与 HUD 独立、清理和重置。闪烁只是提供的反馈，不是求解者工作。 |

素材替换：`og-web-0016` 用本地原创 SVG 盾牌／心形替代两个源位图，用共享 CSS 8 px 等宽主题替代字体／主题包；`og-web-0032` 用直接编写的药水 SVG 替代物品位图；`og-web-0033` 用 128×128 本地星形 SVG 替代 346×324 PNG，同时保留 .58 精灵缩放和明确要求的 72×72 碰撞区域。位图尺寸与碰撞矩形不意味着共用边界框，二者分别检查。加载、组合、资源绑定和布局要求保留，不宣称字形或美术相同。替换记录写在这里，不作为求解者提示词中的免责条款。

八项均通过本地三次重复检查、行为变异、视觉故障和起始项目拒绝检查。FSM 的 actor 绑定变异由会崩溃的空 actor 改为可运行的错误 actor，以证明拒绝源于身份检查而非崩溃。状态栏心形路径在通过检查前修正。拖动缩放变异暴露了检查框架的入口路由问题；`/` 现在接收针对 `index.html` 的变异，修复后完整任务通过。伤害清理探针与提供的控制器一样允许标签已移除，通过额外调用发现残留订阅，而非依靠空标签崩溃。最终证据按当前共享文件记录于 `validation/task-audit.json`。
