## 运行与查看

```powershell
node scripts/reaccept.mjs prepare artifacts/batches/BATCH_ID
node scripts/reaccept.mjs run artifacts/reevaluations/REACCEPT_ID
node scripts/progress.mjs artifacts/batches/BATCH_ID 8081
```

打开 `http://127.0.0.1:8081/reaccept` 查看最新重验、新旧证据和历史轮次。
原进度页与人工复审页仍保留原始自动成绩。人工复审记录不会被自动填写或覆盖。

重验运行前后核对原提交和原始成绩哈希，并冻结当前验收器哈希。
中断后重复同一 `run` 命令会跳过已验收项；基础设施错误会保留到 retry_history
并重试。若验收器再次改变，应准备独立的新轮次，而不能接续混合版本。

这批结果来自部分任务、且原生成运行器经历过修复，因此仍为诊断结果。
重验通过只表示当前公开功能合同的私有检查通过，不等于美术质量通过、人工审阅
通过、完整 228 题模型基线完成或正式 v1 发布门禁通过。
