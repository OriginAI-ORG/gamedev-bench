# 修复卡牌拖拽的目的容器

提供的卡牌交互系统已经完整，但拖拽时会把卡牌移到错误容器。`config.json` 描述 UI 根、底部面板、手牌容器和专用拖拽层。

- **R1 — 查找正确父容器。** 修复 `placement.js` 中的 `moveToDragLayer(card)`。通过场景服务使用配置的拖拽分组。其成员是 UI 根下的专用拖拽层，与底部面板并列。手牌容器的直接父容器不是拖拽目的容器。
- **R2 — 保持坐标。** 使用提供的保持位置辅助函数切换父容器。跨越嵌套层级时全局位置和指针支点必须保持不变，后续移动必须跟随指针减支点的位置。取消时恢复原手牌索引和布局定位。
- **R3 — 保留交互。** 保留所有配置尺寸、名称、标题和计时值，以及 256 乘 144 的场景和 25 乘 30 的卡牌。保留 0 到 3 的状态、检测、真实矩形重叠、右键立即取消、每次拖拽重新计时、有效区域打出和空区域释放后等待下一次输入才归位的行为。新增卡牌、状态和重置必须正常工作。

只修改 `placement.js`，其他文件保持不变。提交完整文件包，以 `index.html` 为入口。验收检查父容器身份、全局坐标、卡牌顺序、计时和实际指针交互。
