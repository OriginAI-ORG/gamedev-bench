# 平滑的绕障追踪

补全浏览器游戏中缺失的追踪组件。提供的瓦片渲染器、碰撞服务和路径规划器已经实现关卡；你的工作是控制器行为与组件组装。

- **R1 — 组装。** 在 `setup.js` 中为角色添加 `Navigation` 子对象，其下包含 `Agent` 和 `Timer`。使用提供的服务。构造 `Controller`，将其配置指定的目标属性绑定到 `objects` 中由 `config.target` 指定名称的实时对象，并把定时器超时事件连接到 `onTimer()`。返回这些组件及用于断开监听、停止定时器的 `dispose()` 函数。
- **R2 — 连续运动。** 补全 `controller.js` 中的 `physics(dt)`。每个物理步都调用 `nextPathPosition()`。将角色当前全局位置指向该路径点的向量归一化；长度为零时使用零向量。按 `acceleration * dt` 权重，将各速度分量插值到方向乘以 `speed`，然后调用 `moveAndSlide(dt)`。保留提供的默认值：速度 300、加速度 7。每一步读取它们的当前值。
- **R3 — 实时目标刷新。** 定时器自动启动，每 0.1 秒触发一次。`onTimer()` 将绑定对象当前的全局位置复制给 `agent.targetPosition`；目标缺失时不执行操作。重复移动目标及继承的父对象偏移都必须体现。保存对象引用，不能保存初始位置快照或名称字符串。
- **R4 — 关卡集成。** 保留提供的 101 个围栏格、720 个地形格、32 像素瓦片、图像和摄像机。角色起点为 (317,246)，目标起点为 (610,250)。保留角色半径 12、碰撞层 2、掩码 1、浮动运动和零最小沿墙滑动角。沿提供的可通行路径连续运动，不进入墙体；在模拟 30 秒后，与可达静止目标的距离应不超过 20 像素。
- **R5 — 浏览器交互。** 保留提供的画布、运行/暂停、0.1 秒步进、10 秒推进和重置控件。点击空地移动目标；点击墙体无效。运行中的追踪必须响应目标变化。重置恢复场景。渲染必须反映角色的实际位置。

只修改 `controller.js` 和 `setup.js`，其余提供的文件保持不变。提交以 `index.html` 为入口的完整浏览器包。公开反馈检查可见运动；私有验收还检查速度计算、定时器周期、对象身份、清理、无穿墙轨迹和目标切换。路径规划器已提供，无需重新实现。
