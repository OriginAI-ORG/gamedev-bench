# 连接目标查找器的检测器

浏览器游戏已经包含完整的检测和目标选择组件，但目标查找器只有角色引用，缺少检测器引用。

- **R1 — 修复绑定。** 在 `bindings.js` 中补全 `bind(unit, config)`，使 `unit.targetFinder.detector` 引用准确的 `unit.detectRange` 对象。保留角色绑定和属性转发。`DetectRange` 与 `TargetFinder` 保持为单位的同级子对象；`Collider` 保持在检测器内部。
- **R2 — 保留行为。** 保持队伍 0 以 enemy_units 为目标、队伍 1 以 player_units 为目标。基础范围为 36；玩家攻击范围 2 得到半径 72。保留 24 乘 24 的单位碰撞体、检测器碰撞层 `4 * (team + 1)`、掩码 `2 - team`、类型过滤的重叠事件及成员变化通知。查找器按全局距离平方搜索整个敌方组，独立于范围成员关系。
- **R3 — 验证集成。** 初始最近单位 (50,0) 位于范围内，另一个单位 (130,0) 位于范围外。将远处单位移动到 (10,0) 后切换最近目标。将两者移到 (300,0) 后清空范围列表，但保留最近目标。保留全部提供的控件、渲染、重复属性更新和监听清理。

只修改 `bindings.js`。其余提供的文件保持不变，提交以 `index.html` 为入口的完整包。验收检查引用身份、对显式检测器的实际事件订阅、双方队伍、位置变化、渲染和清理。无需重写已提供的组件实现。
