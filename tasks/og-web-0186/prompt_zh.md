# 连接拖拽层切换与手牌归位

浏览器场景已经提供可工作的卡牌状态、输入转发和重叠检测。`config.json` 定义手牌容器、拖拽层、分组、投放区、标题和拖拽时限。目前缺少两处连接。

- **R1 — 拖拽层。** 完成 `placement.js` 中的 `moveToDragLayer(card)`。通过提供的场景服务查找配置的拖拽分组，并用提供的保持位置辅助函数把卡牌移入其中。目的容器是 UI 根下与底部面板并列的专用拖拽层；手牌容器位于面板内部。保持全局位置和指针支点不变。
- **R2 — 手牌归位。** 完成 `hand.js`。将每张新卡牌的 `reparent-requested` 事件连接到归位处理，恢复到原手牌容器和原索引，索引限制在当前子元素数量内。恢复布局定位并保持其他卡牌顺序。销毁手牌容器时断开这些监听。保留提供的卡牌创建和状态初始化。
- **R3 — 保留玩法。** 保留 0 到 3 的状态 ID、25 乘 30 的卡牌、256 乘 144 的场景和所有配置值。右键按下立即取消；每次拖拽时限之前松开左键应被忽略。在有效区域释放会打出卡牌；空区域释放保持 Released，直到下一次输入才归位。真实矩形重叠、标签、加牌和重置必须继续正常工作。

只修改 `placement.js` 和 `hand.js`。提交完整文件包，以 `index.html` 为入口。验收覆盖嵌套父容器坐标、计时、反复取消、原顺序、新增卡牌和实际指针打出。
