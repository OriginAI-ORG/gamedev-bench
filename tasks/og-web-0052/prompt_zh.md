# 添加八方向非循环死亡动画

完成 `game/` 中配套浏览器场景的 `component.js`；保留 `index.html`。题包已提供玩家、idle/run 动画、方向映射、碰撞体和精灵速率缩放。添加缺失的死亡片段，不要重建已有资源。

- **R1 — 保留并扩展。** 导出 `configurePlayer(player, services)`，返回同一玩家，并保留其已有精灵、碰撞体、idle/run 片段及帧对象。保持浮动模式、默认 `idle0`、第 0 帧和 `speedScale = 2`。
- **R2 — 死亡帧。** 添加配套 Clip 对象 `death0`–`death7`，使用 `assets/crusader_death.png` 中每方向全部 9 帧。Frame 对象引用完整均匀图集矩形 `[x, y, width, height]`，不加边距、不裁剪。图集包含 8 个方向行。每个 death 索引必须与已有 idle/run 同索引朝向相同；观察配套映射和图像。按列递增构成序列。
- **R3 — 时间与完成。** 将每个死亡片段的基础 FPS 设为 10，关闭循环。保留精灵速率缩放 2，因此死亡动画实际以 20 FPS 推进，并在 0.45 秒后完成。保持最后一帧可见，每次播放只发送一次配套 animation-finished 事件；继续推进不得重播或再次发送完成事件。片段元数据正确时，现有 Sprite 辅助类会提供播放及通知。
- **R4 — 配套环境。** 保留实际图像渲染、方向控件、Idle/Run/Death、Pause / Play、Advance 0.1 s、Probe pointer 和 Reset。初始预览暂停；动作/方向选择后实时播放。重置在新实例中恢复原始 idle0/第 0 帧及零完成计数。保留美术署名和授权文件。

验收检查全部死亡矩形及方向、已有对象身份保留、10 FPS/非循环元数据及继承速率缩放、实际末帧/完成时间和次数、真实图集像素及重置。公开示例选择 Death。不得修改检查或伪造结果。
