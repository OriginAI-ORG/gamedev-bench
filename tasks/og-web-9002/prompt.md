# 翻牌配对 · 任务版本 0.1.0

创建纯本地 HTML、CSS、JavaScript 网页游戏，入口为 index.html。无外部依赖或网络资源。

通过 URL 参数 deck 读取 JSON 数组；合法牌组有 2～8 对，每个字母恰好出现两次。
未指定时使用 ["A","B","A","C","B","C"]。

- 初始所有牌背面朝上，以可见文字「?」表示。
- 点击一张隐藏牌显示其字母；重复点击同一张不能当成第二张或增加次数。
- 翻开两张不同的隐藏牌计一次尝试；匹配后保持正面，配对数加一。
- 不匹配时两张牌先保持正面；至少 300ms、至多 700ms 后一起回盖。
- 不匹配两张的等待期间忽略第三张点击，不能翻开第三张或改变已有两张。
- 匹配牌不能再次参与配对；只有全部匹配后显示「胜利」，否则「进行中」。
- 点击「重新开始」立即取消未完成计时器，恢复原牌序、全部背面、尝试 0、配对 0、进行中。

可观察契约：

1. id 为 board 的可见棋盘，其直接子元素是可点击的 button。
2. 每个牌按钮有唯一 data-index，从 0 连续编号；可见文字仅为 ? 或对应字母。
3. id 为 attempts 的可见元素仅显示尝试次数；id 为 pairs 的可见元素仅显示完成配对数。
4. id 为 status 的可见元素仅显示「进行中」或「胜利」。
5. 重新开始按钮可通过可访问名称「重新开始」定位。
6. 交互后的同步状态在 100ms 内可见；配对等待按上述 300～700ms。

公开调试：点击索引 0、2，应该保留两张 A，配对 1、尝试 1；重新开始后全部归零。
正式验收使用同一契约下的其他牌序及交互顺序。不限定 CSS 布局和内部实现。
