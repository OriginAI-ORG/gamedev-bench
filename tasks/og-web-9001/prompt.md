# 推箱子 · 任务版本 0.1.0

请在空白工程中实现可直接运行的网页推箱子游戏，入口为 index.html。
只使用本地 HTML、CSS、JavaScript 和自行绘制的图形，不使用网络资源或服务端。

## 游戏规则

- 方向键控制玩家。墙壁不可进入，棋盘外不可进入。
- 玩家可推一个箱子前进一格；箱子后方是墙、另一箱子或棋盘外时不得移动。
- 只有实际移动成功才累计一步，成功推箱也算一步。撞墙与失败推箱不计步。
- 所有箱子都在目标上才显示「胜利」，否则显示「进行中」。
- 胜利后方向键不再改变棋盘或步数。
- 名为「重新开始」的可见按钮恢复当前地图、玩家、箱子和步数，状态恢复为该地图的初始状态。
- 同一游戏运行中重开与连续键盘输入必须可靠。

## 输入与可观察界面契约

通过 URL 参数 map 读取 JSON 字符串数组，例如：

~~~js
const rows = JSON.parse(new URLSearchParams(location.search).get('map'));
~~~

地图必须是至少 3 × 3 的矩形；合法测试地图恰好一个玩家、至少一个箱子，箱子与目标数量相等。
字符意义：# 墙，空格 地面，. 目标，$ 箱子，@ 玩家，* 目标上的箱子，+ 目标上的玩家。
无 map 参数时使用以下公开地图：

~~~json
["#######", "#     #", "# .$@ #", "#     #", "#######"]
~~~

为使自动验收能操作不同实现，页面必须提供以下真正可见的 DOM 控件：

1. id 为 board 的棋盘，以可见二维网格呈现地图，每个格子为 board 的直接子元素。
2. 每个格子包含 data-row 和 data-col，均从 0 开始，唯一对应地图坐标。
3. 格子可见文字使用下列符号，格子中只能有对应符号；空格地面显示「·」。

| 内容 | 可见文字 |
|---|---|
| 墙 | # |
| 地面 | · |
| 目标 | ○ |
| 箱子 | □ |
| 玩家 | @ |
| 目标上的箱子 | ■ |
| 目标上的玩家 | ⊕ |

4. id 为 steps 的可见元素仅显示十进制步数。
5. id 为 status 的可见元素仅显示「进行中」或「胜利」。
6. 可通过可访问名称「重新开始」定位的 button。

允许自由选择颜色、尺寸、字体和周边布局。建议以不同颜色区分墙壁、目标和箱子。
本题 v0.1 只评估 DOM 网格实现；Canvas-only 不属于本次契约。
有效操作后的界面更新应在 200 毫秒内完成。页面不得产生未捕获异常。

## 公开调试示例

公开地图从第 2 行、第 4 列开始。按 ArrowLeft 推箱到目标，应显示步数 1、胜利。
点击「重新开始」后恢复原地图、步数 0、进行中。
正式验收使用同一公开契约下的其他合法地图与操作顺序，不要求特定代码结构。
