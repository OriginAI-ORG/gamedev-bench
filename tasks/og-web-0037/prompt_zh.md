# 为平台控制器添加加速和摩擦

补全 `component.js` 中的 `configureMovement(player)`，并修改 `physicsStep(player,input,dt)`。所提供的角色、位图、碰撞框、重力、碰撞积分和跳跃行为已经可用。保留这些功能，修改水平响应。

- **R1 — 参数。** 在同一个角色上配置默认值为 0.1 的 `friction` 和默认值为 0.25 的 `acceleration`，并返回该角色。两者通过现有控件在 0 到 1 之间编辑。保留既有初始参数：速度 1200、跳跃速度 -1800、重力 4000。
- **R2 — 缓存方向并加速。** 每次物理更新只读取一次 `input.getAxis()`，存入局部方向变量。方向非零时，从当前水平速度向方向 ×速度做线性插值，用当前加速度作为插值权重，并以结果替换水平速度。例如，从静止开始向右输入，前两次水平速度分别为 300 和 525。
- **R3 — 摩擦。** 方向为零时，以当前摩擦作为权重，将水平速度向 0 插值。从速度 525 开始，一次无输入更新得到 472.5。每次物理更新直接应用这些权重，不乘以经过时间。所提供的浏览器时钟每秒进行 60 次物理更新。
- **R4 — 保留垂直物理。** 向垂直速度加上重力 ×dt，执行水平控制，再调用一次 `player.moveAndSlide(dt)`。随后，仅在 `input.justPressed('jump')` 和 `player.isOnFloor()` 均为 true 时应用跳跃速度。水平插值不能改变当前垂直速度，并须保留地面碰撞及空中跳跃拒绝行为。
- **R5 — 使用当前参数。** 读取当前速度、摩擦和加速度。权重 0 保持水平速度不变；权重 1 在一次更新中达到目标。保留所提供的角色、精灵和碰撞框对象，以及实际由键盘驱动的场景。
- **R6 — 检查与重置。** 保留播放/暂停、1/60 秒单步、方向控件、空格跳跃、参数输入和重置。显示实际移动，保留原位图。重置恢复默认参数和静止角色。

验收检查速度序列、方向反转、单次输入采样、参数极值、操作顺序、跳跃、着陆、实际绘制移动和键盘控制。保持本地页面可通过 `index.html` 运行。
