# 切分并驱动移动恐龙的动画

补全 `component.js` 中的 `configurePlayer(player,{Sprite,Clip,Animator})` 和 `updatePlayer(player,axis)`。浏览器配套场景提供可移动物体、重力、地面碰撞、跳跃、控件和图像绘制。配置精灵与动画，再驱动水平移动和朝向。

- **R1 — 精灵图集。** 使用所提供的 `Sprite` 类创建 `player.sprite`，读取 `dino.png`，将这张 576×24 图像切分为 24 列、1 行。保持其局部位置 [0,-2]。使用原有位图单元。
- **R2 — 动画片段。** 使用所提供的 `Animator` 和 `Clip` 类创建 `player.animator`。其 `default` 片段按顺序使用第 0–3 帧；`run` 按顺序使用六个跑步帧 4–9。两者均以每秒 5 帧循环播放，时长分别为 0.8 和 1.2 秒。每个片段只有一条轨道，指向原精灵的 `frame` 属性，关键帧间隔 0.2 秒。初始播放默认片段。
- **R3 — 水平控制。** 输入轴为 -1、0 或 1。将 `player.velocity[0]` 设为输入轴 ×100 像素每秒。非零输入播放跑步，零输入播放默认动画。同一状态下的重复更新必须允许动画继续推进，不能不断重新开始。
- **R4 — 朝向与集成。** 向左移动时设置 `player.sprite.flipH`，向右移动时清除它。静止时保留上次朝向。保留垂直速度、所提供的物体、碰撞框和跳跃行为。配置函数返回同一个角色。所提供的物体根据经过时间对速度积分。
- **R5 — 可见结果。** 方向键和方向按钮必须影响实际移动、位图动画和水平镜像。保留播放/暂停、0.05 秒单步、空格跳跃和重置。重置恢复初始默认动画及向右姿态。

所提供的 `Sprite` 接受图像路径、列数、行数和选项。`Clip` 接受 `duration`、`step`、`loop` 和 `tracks`；轨道包含 `target`、`property`，以及由 [时间,值] 对组成的 `keys`。验收检查切分、全部选定帧、经过时间对应的移动、相位连续性、镜像、键盘输入和实际绘制像素。保持本地页面可通过 `index.html` 运行。
