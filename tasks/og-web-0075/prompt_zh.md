# 配置静音的启动音乐

补全 `component.js` 中的 `configureMusic(voice,{mixer,registry})`。所提供的应用已经具备一个音频声部、Master、Music、Sounds 总线、启动播放支持和持久服务注册表。本题是配置任务。

- **R1 — 音乐来源。** 将所提供声部的 `src` 设为 `music.ogg`，使用原始本地音频文件；将其 `bus` 设为 `Music`。将 `autoplay` 设为 true，并返回同一个声部。
- **R2 — 全局注册。** 使用 `registry.set(name,voice)`，将原声部注册到 `MusicPlayer` 键下。切换场景后它必须仍然可访问，并继续同一次播放。
- **R3 — 独立静音设置。** 对 `Master` 和 `Music` 分别调用 `mixer.setMuted(name,true)`。保留 Sounds 总线现有的非静音状态。静音必须影响实际输出增益，不能通过禁止播放或移除音频流实现。
- **R4 — 启动行为。** 所提供的开始会话按钮解锁浏览器音频。首次解锁后，应用现有的启动机制必须立即开始播放已注册且启用自动播放的声部，不需要额外播放命令。它必须解码原文件、推进播放，并在任一要求的总线静音时保持无声。
- **R5 — 检查与重置。** 保留所提供的波形、独立 Master 和 Music 静音控件、场景切换和重置。只取消其中一个要求的总线静音时仍应无声；两者都取消静音时，正在播放的音乐应可听见。重置恢复两个静音设置及启动配置。

浏览器音频权限入口、解码和声部生命周期支持均已提供。验收检查对注入的声部/混音器/注册表的配置、原素材完整性、解锁后的真实自动播放、两个独立增益、实际输出采样及跨场景的服务身份。保持页面可通过 `index.html` 运行。
