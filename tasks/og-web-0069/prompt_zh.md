# 对齐竖向陷阱生成标记

完成 `game/` 中配套本地浏览器场景的 `component.js`；保留 `index.html`。请检查提供的 64×64 `trap.png` 位图。精灵原点位于图像中心，无需重绘图像。

- **R1 — 结构。** 导出 `configureTrap(trap, Node)`。用配套场景对象构造函数创建并返回一个 `SpawningPoints` 子对象，其中包含 `SpawnTop` 和 `SpawnBot`。保留已有 `Sprite`、其位置和旋转。
- **R2 — 视觉对齐。** 将 SpawnTop 放在实际位图的上方尖刺尖端，SpawnBot 放在下方尖刺尖端，误差在 2 个图像空间像素内。不能用矩形中心代替，也不能将图像重新居中。根据可见形状确定局部坐标。
- **R3 — 层级与变换。** SpawnTop 的 `z = 0`，SpawnBot 的 `z = 1`。两者都挂在容器下，继承父级移动/旋转。层级 0.5 的探测遮挡物必须盖住 SpawnTop，而 SpawnBot 仍在前方。
- **R4 — 配套环境。** 保留 Move parent、Rotate parent、Toggle layer probe 和 Reset。根对象初始位于 [300, 190]，移动增加 [40, 20]，旋转增加 90 度。重置后恰好两个标记，恢复原始对齐位置并关闭探测遮挡物。

验收检查配套位图、尖端对齐、精灵保持不变、层级、变换后的可见位置、实际绘制顺序和重置。公开示例移动父级。不得修改检查或伪造结果。
