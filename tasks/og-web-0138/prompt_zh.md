# 为宝石贴合紫色高亮

查看原始 `assets/platformer_coins.jpg`，并完成 `overlays.json`。保持 `level.json`、图像和提供的浏览器绘制器不变。根据插画场景确定宝石位置和外轮廓。

- **R1 — 场景层次。** 保留 `Level` 的位置、缩放和旋转，以及图像单独的局部偏移和左上角原点。将 `GemstoneHighlights` 保持在 Level 下，与图像同级。多边形与图像必须继承相同父级变换。
- **R2 — 宝石形状。** 在 GemstoneHighlights 下添加一个名为 `GemstoneHighlight` 的多边形。使用至少 4 个顶点紧贴紫色宝石，包括下方尖端。高亮是独立形状，不是替代图像的一部分。
- **R3 — 紧密覆盖。** 尽量减少超出宝石的部分。验收要求与 Level 局部坐标中的标注轮廓交并比至少为 0.85，计算包括多边形自身和容器组的变换。覆盖率使用像素中心采样，允许不同顶点表示方式。
- **R4 — 紫色半透明填充。** 有效 alpha 必须严格介于 0 和 1 之间，并能明显透出下方原图。有效归一化红色须在 [0.35,1]，绿色在 [0.05,0.75]，蓝色在 [0.45,1]，且蓝色大于绿色。必须使用满足这些范围的紫色或粉紫色填充。
- **R5 — 可检查组合。** 保留显示高亮和重置视图控件。隐藏多边形时显示完整原图，重置后恢复对齐的高亮。可见多边形必须改变宝石区域的像素。不得将原图替换成预合成截图。

覆盖文档包含 `name`、可选的 `position`、`scale`、`rotation`，以及 `children`。每个多边形包含 `name`、以 [x,y] 表示顶点的 `points`、归一化 RGBA `color`，以及可选的位置、缩放、旋转和 `modulate`。默认位置 [0,0]、缩放 [1,1]、旋转 0 弧度、调制 [1,1,1,1]。有效颜色由颜色与调制逐分量相乘。提供的绘制器负责层次和绘制。验收检查原始素材、变换、几何重叠、色调、透明度和实际覆盖像素。保持 `index.html` 可运行。
