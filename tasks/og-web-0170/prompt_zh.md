# 从角色刷新检测器

提供的检测器通过角色引用推导碰撞设置和圆形范围，但单位的属性更新钩子尚未赋予该引用。

- **R1 — 传递角色。** 补全 `bindings.js` 中的 `applyStats(unit, config)`，将准确的单位赋给 `unit.detectRange.actor`。每次调用都执行，包括重复修改属性时。保留 `unit.targetFinder.actor` 和检测器与查找器同级的结构。
- **R2 — 保留派生状态。** 检测器读取角色当前属性，生成碰撞层 `4 * (team + 1)`、掩码 `2 - team` 和半径为基础范围乘以攻击范围的新圆形。默认基础范围为 36、玩家攻击范围为 2，得到半径 72；单位碰撞体保持为 24 乘 24。之后更改队伍或攻击范围时，必须立即更新所有派生值，且不改变其他单位状态。
- **R3 — 保留选敌。** 队伍 0 以 enemy_units 为目标，队伍 1 以 player_units 为目标。初始敌方位于 (50,0) 和 (130,0)，得到一个范围内单位和最近目标。将远处单位移至 (10,0) 后切换目标；将两者移至 (300,0) 后清空成员。保留整个敌方组的最近搜索、类型过滤事件、可见控件和清理。

只修改 `bindings.js`，其余文件保持不变。提交以 `index.html` 为入口的完整包。验收检查实时角色身份、替换形状、双方队伍、重复属性更新、实际重叠和渲染结果。
