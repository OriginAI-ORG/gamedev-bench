# 复制镜像陷阱

完成 `game/` 中配套本地浏览器场景的 `component.js`；保留 `index.html`。配套环境提供完整 TrapBot 和原始 64×64 `trap.png` 位图。

- **R1 — 复用。** 导出 `createTrapTop(root, bottom)`。深度复制传入的下方陷阱，将新实例命名为 `TrapTop`，直接挂在相同根对象下并返回。保留其他所有属性及子对象，包括贴图、元数据、标记名称、局部坐标和层级。不能修改下方陷阱，也不能与其共享可变子对象/变换/属性对象。
- **R2 — 指定改动。** 将 TrapTop 的局部位置设为 [0, -32]，只把它的 `Sprite` 子对象旋转设为 270 度。保持陷阱根对象的旋转不变。TrapBot 保持在 [0, 32]，Sprite 保持 90 度，因此两个陷阱原点相距 64 单位。
- **R3 — 标记。** 两个陷阱分别保留自己的 `SpawningPoints` 容器，其中 `SpawnLeft` 位于 [-15, 0]、`z = 0`，`SpawnRight` 位于 [15, 0]、`z = 1`。只旋转 Sprite 不能带动标记容器旋转。显示全部四个标记；层级 0.5 的探测遮挡物盖住左标记，右标记绘制在前方。
- **R4 — 配套环境。** 保留 Move parent、Rotate parent、Toggle layer probe 和 Reset。根对象初始位于 [300, 190]，移动增加 [40, 20]，旋转增加 90 度。两个完整陷阱实例都继承这些变换。重置恢复原始的一对陷阱、四个标记并关闭探测遮挡物，不得重复创建。

验收将每个复制属性与提供的实例对比，检查可变数据独立性及两项允许改动、全部四个标记坐标/层级、位图复用、实际渲染变换、绘制顺序和重置。公开示例移动父级。不得修改检查或伪造结果。
