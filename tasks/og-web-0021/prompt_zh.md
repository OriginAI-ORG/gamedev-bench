# 安装高优先级胸部锚点

完成 `game/` 中配套本地浏览器游戏的 `component.js`；保留 `index.html`。配套环境提供空间层级、透视投影、注册集合和可复用的 `FlashlightPoint` 类。

- **R1 — 挂载。** 导出 `installPoint(chest, Point, registry)`。创建一个名为 `FlashlightPoint` 的配套 `Point` 实例，以局部坐标 `[0, 0, 0]` 直接挂载到 `chest`，用 `registry.add(point)` 注册同一个实例，并将其返回。
- **R2 — 优先级。** 将优先级设为 `Point.Priority.high`（配套类中为 3）。保留配套点对象初始为 false 的 `hasBeenTargeted` 状态及重置行为。配套环境必须能通过注册集合发现并定位它。
- **R3 — 既有场景。** 保持现有 `ChestTarget` 对象、父级和局部坐标 `[0, 0.25, 0]` 不变。胸部容器保持在 `[0, 1.45, 0]`，绕 Y 轴旋转 180 度。新锚点必须继承父级变换，从实际世界坐标投影，不能固定在屏幕坐标上。
- **R4 — 集成。** 保留定位、场景移动、相机移动、目标状态重置和环境重置控件。定位时光束指向此锚点；目标重置清除其状态。完整重置恢复一个已注册锚点和未被修改的胸部目标，不得重复创建。

验收通过独立提供的点类检查实例与引用身份、高优先级、父级及局部/世界坐标、既有目标保留、投影标记移动、定位和重置。公开示例定位新锚点。不得修改检查或伪造结果。
