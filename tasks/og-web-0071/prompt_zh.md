# 对齐横向陷阱生成标记

完成 `game/` 中配套本地浏览器场景的 `component.js`，保留 `index.html`。提供的 64×64 `trap.png` 精灵已经旋转 90 度。

- **R1 — 层级。** 导出 `configureTrap(trap, Node)`。用配套场景对象构造函数创建并返回一个 `SpawningPoints` 子对象，其中包含 `SpawnLeft` 和 `SpawnRight`。保持已有 `Sprite` 对象身份、位图、位置和 90 度旋转。
- **R2 — 图像对齐。** 在精灵旋转后，将 SpawnLeft 放到可见左侧尖端，将 SpawnRight 放到可见右侧尖端，误差在 2 个图像空间像素内。根据配套位图推导陷阱局部坐标；标记属于容器，不能跟着精灵再次旋转。
- **R3 — 顺序与变换。** SpawnLeft 的 `z = 0`，SpawnRight 的 `z = 1`。两者都继承陷阱的父级变换。层级 0.5 的探测遮挡物盖住左标记，右标记绘制在前方。
- **R4 — 配套环境。** 保留 Move parent、Rotate parent、Toggle layer probe 和 Reset。根对象初始位于 [300, 190]，移动增加 [40, 20]，父级旋转增加 90 度。重置恢复恰好两个正确对齐的标记，并关闭探测遮挡物。

验收检查局部尖端对齐、精灵属性保留、层级、变换后的实际渲染位置、位图可见性、绘制顺序和重置。公开示例移动父级。不得修改检查或伪造结果。
