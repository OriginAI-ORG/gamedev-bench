# Build an adjustable multi-tile moving platform

Complete `configurePlatform(platform,services)`, `setupLength(platform)`, `clearCollisionShapes(mover)` and `addCollisionShape(mover,shape)` in `component.js`. The supplied scene already moves a platform and carries a detected rider. Implement reusable tile assembly and detector rebuilding.

- **R1 — Hidden templates.** Add a `Node2D` named `Templates`, hidden from rendering, and retain it as `platform.templates`. Move the supplied sprite and collision shape from the segment area into it. Preserve the original `tile_0108.png` texture, uncentered 16×16 sprite and 14×14 rectangle centered at [8,8]. The templates must not move when copies are offset.
- **R2 — Editable length and spacing.** Expose integer `platform.length` from 1 to 5, initially 1, and `platform.tileOffsetAmount`, initially [16,0]. Changing length must immediately rebuild the preview, including while playback is paused. Explicit calls to setupLength must also rebuild from the current values.
- **R3 — Rebuild segments.** Clear old children from `platform.area`. For each tile index starting at 0, clone both templates and add index ×tile offset to each clone's original local position. Rebuild correctly when length increases, decreases or is assigned again. Keep the area's existing collision settings.
- **R4 — Matching rider detectors.** Extend the existing `platform.mover` with working clear and add collision-shape helpers. On every rebuild, clear its old detector shapes and add a distinct copy for every platform shape, with matching position and size. Do not share mutable position or size arrays between copies or templates.
- **R5 — Preserve integration.** Return the same platform. Keep the existing mover, detector, speed [32,0], displacement events and rider attachment behavior. A rider over any generated tile must move with the platform; a rider outside the rebuilt detector must detach. The detector uses layer 0 and mask 2; the segment area uses layer 16 and mask 0.
- **R6 — Visible editing.** Retain length and offset inputs, the actual source image, Play/Pause, the 0.25-second step, click-to-place rider and Reset. Render the generated tiles and collision outlines. Reset restores the original length, spacing, position and rider.

Services supply `Node2D`, `Sprite` and `CollisionShape`; nodes support `add`, `remove` and `clear`, and template objects support `clone`. Acceptance checks detached old children, independent copies, arbitrary two-axis offsets, repeated length changes, detector coverage and actual rider movement. Keep the local page runnable through `index.html`.
