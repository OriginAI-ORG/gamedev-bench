# 构建可调长度的多瓦片移动平台

补全 `component.js` 中的 `configurePlatform(platform,services)`、`setupLength(platform)`、`clearCollisionShapes(mover)` 和 `addCollisionShape(mover,shape)`。所提供的场景已经能移动平台并携带检测到的乘客。实现可复用的瓦片组装和检测形状重建。

- **R1 — 隐藏模板。** 添加名为 `Templates`、不参与绘制的 `Node2D`，并保存为 `platform.templates`。将所提供的精灵和碰撞形状从分段区域移入其中。保留原有 `tile_0108.png` 纹理、不居中的 16×16 精灵，以及中心位于 [8,8] 的 14×14 矩形。对副本施加偏移时不能移动模板。
- **R2 — 可编辑长度和间距。** 提供整数 `platform.length`，范围 1 到 5，初始为 1；提供 `platform.tileOffsetAmount`，初始为 [16,0]。修改长度必须立即重建预览，包括暂停播放时。显式调用 setupLength 也必须根据当前参数重建。
- **R3 — 重建平台分段。** 清除 `platform.area` 中的旧子对象。对从 0 开始的每个瓦片索引，复制两个模板，并在每个副本原有局部位置上加上索引 ×瓦片偏移。长度增加、减少或重复赋值时都要正确重建。保留区域既有的碰撞设置。
- **R4 — 匹配的乘客检测形状。** 为既有 `platform.mover` 扩展可用的清空和添加碰撞形状辅助方法。每次重建都清除旧检测形状，并为每个平台碰撞形状添加独立副本，使位置和大小一致。副本和模板之间不能共享可变的位置或大小数组。
- **R5 — 保留集成。** 返回同一个平台。保留现有移动器、检测器、速度 [32,0]、位移事件和乘客附着行为。任意生成瓦片上的乘客都应随平台移动；位于重建后的检测区域之外的乘客应脱离。检测器使用层 0、掩码 2；分段区域使用层 16、掩码 0。
- **R6 — 可见编辑。** 保留长度和偏移输入、实际源图像、播放/暂停、0.25 秒单步、点击放置乘客和重置。绘制生成的瓦片与碰撞轮廓。重置恢复原始长度、间距、位置和乘客。

服务提供 `Node2D`、`Sprite` 和 `CollisionShape`；节点支持 `add`、`remove` 和 `clear`，模板对象支持 `clone`。验收检查旧子对象脱离、独立副本、任意双轴偏移、重复长度变化、检测覆盖及实际乘客移动。保持本地页面可通过 `index.html` 运行。
