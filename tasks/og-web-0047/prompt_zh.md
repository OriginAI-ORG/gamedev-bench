# 将八个动画方向匹配到独立图像序列

完成 `game/` 中配套浏览器场景的 `component.js`；保留 `index.html`。观察 Crusader 图像：素材方向编号与动画索引不同。题包提供精灵/片段类、播放和碰撞检查功能。

- **R1 — 组装。** 导出 `configurePlayer(player, services)`，配置并返回同一玩家。设置 `motionMode = 'floating'`，指定配套 Sprite，默认为 `idle0` 第 0 帧，并设置 `speedScale = 2`。
- **R2 — 方向映射。** 使用 Clip 和 Frame 对象创建 `idle0`–`idle7` 和 `run0`–`run7`。索引 0 朝右，之后按顺时针依次朝右下、下、左下、左、左上、上、右上。观察图像确定对应素材编号；同一方向的 idle 和 run 必须一致。
- **R3 — 完整素材序列。** 每个 idle 方向使用 `assets/idle/` 中全部 16 张图像，每个 run 方向使用 `assets/run/` 中全部 17 张图像，按帧顺序递增排列。每帧使用完整独立图像，不裁剪。片段以基础 5 FPS 循环；精灵缩放后为 10 FPS。不得替换成 walk 帧或重复静态图像。
- **R4 — 脚部碰撞框。** 添加配套 RectangleCollider，设置 `size = [66, 24]` 和 `position = [7, 44]`，相对未裁剪图像中心定位。保留实际命中检测。
- **R5 — 配套环境。** 保留实际 299×240 图像、可见碰撞框、方向控件、Idle/Run、Pause / Play、Advance 0.1 s、Probe pointer 和 Reset。初始预览暂停；选择动作/方向后实时播放。重置恢复 idle0/第 0 帧及新配置组件。保留美术署名和授权文件。

验收检查全部八个视觉方向映射、每张图像/帧、完整循环及速率、默认状态、浮动模式、碰撞几何、实际渲染像素、实时播放和重置。公开示例选择 Run。不得修改检查或伪造结果。
