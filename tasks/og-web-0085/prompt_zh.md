# 居中危险提示对话框

在 `game/index.html` 为浏览器游戏建立危险提示覆盖层。使用本地素材和脚本。

- **R1 — 初始状态。** 载入时游戏场景可见，`#dialog` 保持隐藏。
- **R2 — 打开与内容。** `#open-dialog` 显示一个 `#dialog` 覆盖层，其中包含纯色 `#dialog-box` 和可见文字 `DANGER`。
- **R3 — 最小尺寸。** 面板最小宽度为 240 像素，最小高度为 110 像素；内容清晰可读。
- **R4 — 居中与增长。** 在 800×600 和 1100×760 视口下，面板中心与 `#scene` 中心在两个轴上的距离均不超过 2 像素。调整场景尺寸和将面板两个最小尺寸均增加 80 像素，不得移动此中心。向相反两侧等量增长。
- **R5 — 关闭与重置。** `#close-dialog` 隐藏覆盖层；重新打开时仍恰好只有一个面板。`#reset` 恢复初始隐藏状态。

验收检查实际按钮交互及渲染几何，包括增长。公开示例打开覆盖层。保留选择器，所有资源离线可用，不得读取私有检查或伪造结果。
