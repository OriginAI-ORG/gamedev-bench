# 居中警报对话框

在 `game/index.html` 实现浏览器游戏的警报覆盖层，使用本地素材和脚本。

- **R1 — 初始状态。** 初次载入时，游戏场景可见，`#dialog` 隐藏。
- **R2 — 打开与内容。** 点击 `#open-dialog` 显示一个 `#dialog` 覆盖层，其中包含纯色 `#dialog-box` 和可见文字 `ALERT`。
- **R3 — 最小尺寸。** 面板最小宽度为 220 像素，最小高度为 100 像素。内容必须清晰可读。
- **R4 — 居中与增长。** `#dialog-box` 中心与 `#scene` 中心在两个轴上的距离均不超过 2 像素。在 800×600 和 1100×760 视口下，改变场景尺寸或将面板两个最小尺寸均增加 80 像素后，仍必须保持此中心。增长向相反两侧等量延伸。
- **R5 — 关闭与重置。** `#close-dialog` 隐藏覆盖层。重新打开不得重复创建面板。`#reset` 恢复初始隐藏状态。

验收使用真实按钮点击和实际渲染几何，包括最小尺寸增长。公开示例打开覆盖层。保留指定选择器；不得读取私有检查或伪造测试结果。所有资源必须无需网络即可运行。
