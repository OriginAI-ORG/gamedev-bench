# 组装固定大小的控制菜单

补全浏览器布局预览中的 `panel.html` 和 `panel.css`。本题进行 HTML/CSS 控件组装；预览加载、重置和最小尺寸检查均已提供。

- **R1 — 面板。** 将 `#ui` 设为左对齐、宽 320 像素且跨越整个视口高度的面板。使用提供的面板颜色 [37,56,76]，背景透明度为 200/255。透明度只作用于面板背景，后代元素保持不透明。当提供的 `--minimum-panel-height` 超过视口高度时，以垂直中心为基准向上、向下等量扩展。
- **R2 — 菜单。** 将 `#menu` 放在面板局部位置 [10,0]，宽 300、高 811 像素。将其两个子行纵向排列。视口变化或面板扩展时，菜单保持这些尺寸。
- **R3 — 全屏行。** 添加水平行 `#fullscreen-row`，其中包含 `#fullscreen-label`，文本严格为 `(F)ull Screen: `，以及默认选中的原生复选框 `#fullscreen`。将标签与复选框关联。保留原生指针、焦点和键盘切换行为。
- **R4 — 分形行。** 添加水平行 `#fractal-row`，其中包含 `#fractal-label`，文本严格为 `Select Fractal: `，随后是启用的按钮 `#mandelbrot` 和 `#julia`，分别显示 `Mandelbrot` 和 `Julia`。保留此子项顺序及正常键盘焦点行为。
- **R5 — 预览。** 使用提供的主题，并保持最小高度输入及重置可用。重置重新创建唯一面板，且复选框选中。这些控件是布局示例，不要求实现分形绘制器或全屏应用逻辑。

验收检查准确文本、选中状态、尺寸、层次结构、只作用于面板的透明度、视口调整及居中的最小高度扩展。保持页面可通过 `index.html` 运行。
