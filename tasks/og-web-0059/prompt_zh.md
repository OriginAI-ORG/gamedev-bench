# 创建可复用的四声部音乐播放器

实现 `sound-player.js` 中的 `SoundPlayer`，以及 `component.js` 中的 `createMusicPlayer({mixer,AudioVoice})`。所提供的 Web Audio 引擎已经支持创建声部、总线路由和实际声音输出。诊断音频和检查页面均已提供。

- **R1 — 可复用播放器。** SoundPlayer 通过 `SoundPlayer(children,VoiceType)` 接受有序子对象数组和声部类，并公开这些子对象。其 `play(audio,single=false)` 方法遇到 null 或 undefined 音频时立即返回，不改变任何声部，包括 single 为 true 时。
- **R2 — 首个空闲声部。** 对有效音频，使用第一个属于所提供声部类实例且空闲的子对象。将该音频对象原样赋给它的 `stream`，然后调用其 `play()` 方法。忽略非音频子对象。如果全部声部都忙碌，则保持播放不变，不排队也不抢占声部。
- **R3 — 独占播放与停止。** single 为 true 且音频有效时，先停止所有音频子对象，再选择首个空闲声部。`stop()` 对每个音频子对象调用停止，包括空闲声部。独占请求后恰有一个声部播放。自然播放结束的声部应重新可用。
- **R4 — 音乐播放器组装。** 返回名为 `MusicPlayer` 的 SoundPlayer，恰好包含 4 个新建的 `AudioVoice` 子对象，每个都使用所提供的混音器和总线 `Music` 构造。将 `processAlways` 设为 true，使播放在游戏暂停时继续。
- **R5 — 实际输出与重置。** 保留所提供的播放、独占播放、停止、静音、暂停游戏和重置控件，以及波形和活动指示。播放必须使用真实音频节点，并自然结束。重置停止现有声部并重建初始播放器。

现有引擎提供 Music 总线。诊断缓冲区是测试音频，本题不要求设计声音。验收检查音频对象身份、子对象顺序、空音频/独占行为、池满行为、停止调用、实际路由采样、自然完成及游戏暂停期间的播放。保持页面可通过 `index.html` 运行。
