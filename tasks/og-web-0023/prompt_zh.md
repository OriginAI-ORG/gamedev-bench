# 连接关卡相机、玩家和菜单

完成 `game/` 中配套本地浏览器场景的 `component.js`；保留 `index.html`。题包提供 SceneObject、Camera、玩家工厂、完整菜单工厂/处理器、过渡材质及透视投影。本题要求组装关卡并绑定提供的实例。

- **R1 — 组装。** 导出 `assembleLevel(root, {Camera, createPlayer, createMenus})`。各调用一次提供的工厂。将返回的玩家、命名为 LevelCamera 的新配套 Camera 实例，以及返回的菜单实例作为直接同级对象加入 root。返回包含这些对象本身的 `{player, camera, menus}`。保留玩家的 PlayerCamera 子对象及完整菜单组件；不得重新构造工厂结果。
- **R2 — 静态相机变换。** 将相机位置设为 [-12.2164, 15.8305, 12.4355]，欧氏距离容差为 0.05。将三个基向量列设为 [0.794097, 0, 0.607792]、[0.37447, 0.787656, -0.489255] 和 [-0.478731, 0.616115, 0.625475]，各列容差为 0.01。按此顺序存入 `basis`。它们是相机局部轴在世界空间中的向量，不是欧拉角。组装返回时保持 `current = false`；配套处理器会在启动时激活它。
- **R3 — 绑定。** 将玩家实例本身赋给 `menus.playerNode`，将相机本身赋给 `menus.levelCamera`。保留配套菜单的 `transitionMaterial` 对象身份，以及所有已有方法、面板引用和按钮。玩家与菜单必须属于同一个关卡根对象。
- **R4 — 可见运行效果。** 保留配套启动行为：菜单处理器隐藏玩家、激活 LevelCamera、暂停游戏，并在暂停期间运行 2 秒遮罩淡出。使用当前相机的位置和基向量渲染场景。Play 完成 2 秒过渡后显示玩家、切换到 PlayerCamera 并恢复时间/运动。Pause/Resume 仍可使用；Show death 切回关卡相机并隐藏玩家。保留配套材质驱动的过渡及控件。
- **R5 — 生命周期与浏览器行为。** Restart 和 Reset 重新构造干净关卡，其中有一个玩家、一个静态相机和一个菜单实例，并保持工厂连接及新引用。保留浏览器全屏切换和本地 Quit 过渡到 Session ended 的行为。不得以文字标签或固定截图代替相机渲染。

验收注入不同工厂以检查实例/父级/材质的精确身份，分别检查位置和基向量，以独立相机数学比较地标投影坐标，运行玩家/菜单相机切换及暂停期间操作，并检查干净重建。公开示例检查初始菜单相机。不得修改检查或伪造结果。
