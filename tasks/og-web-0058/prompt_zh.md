# 同步角色上下身动画

补全 `component.js` 中的 `bindAnimations({lower,upper})`。所提供的浏览器场景已经包含两个精灵、动画片段、动画时钟、图像绘制和检查控件。实现事件绑定，并返回用于断开绑定的函数。

- **R1 — 跟随下身动画变化。** 订阅下身播放器的 `animation-changed` 事件，其 `detail` 是新动画名称。调用 `upper.play(name)`，使上身播放相同动画；但当 `upper.current` 为 `attack` 时除外。
- **R2 — 保护攻击动画。** 攻击期间下身动画的变化不能中断或重启上身攻击。不要修改下身播放器的动画或播放位置。
- **R3 — 按当前相位恢复。** 订阅上身播放器的 `animation-finished` 事件。仅当其 `detail` 为 `attack` 时，在上身播放 `lower.current`，然后调用 `upper.seek(lower.position)`。在完成时读取下身的当前状态，最终播放位置差应在 0.05 秒以内。其他完成事件不能触发此恢复操作。
- **R4 — 使用所提供的组件。** 保留播放器、精灵对象及全部片段定义。上下身都具有使用第 6 帧、持续 0.1 秒且不循环的站立片段，以及使用第 0、1 帧、持续 0.2 秒且循环的跑步片段。上身攻击使用第 7、8、9 帧，持续 0.3 秒。实际位图帧和时间推进必须保持可见。
- **R5 — 清理订阅。** 返回的函数移除两个监听器，并允许重复调用。清理后，任何一个事件都不能再调用另一个播放器。重置必须重新建立有效绑定，且不累积监听器。

场景初始暂停。使用动画按钮、播放、0.05 秒单步和重置进行检查。验收覆盖事件传递、攻击中断保护、先播放后定位的顺序、任意完成相位、清理、实际绘制帧和实时播放。保持本地页面可通过 `index.html` 运行。
