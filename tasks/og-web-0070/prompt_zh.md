# 居中陷阱贴图并对齐标记

完成 `game/` 中配套本地浏览器场景的 `component.js`；保留 `index.html`。请检查提供的 64×64 `trap.png`，其精灵原点初始位于图像中心。

- **R1 — 居中主体。** 导出 `configureTrap(trap, Node)`。保留已有 `Sprite` 对象和位图。只调整其局部位置，让位图中矩形主体的中心落在陷阱原点，误差在 2 个图像空间像素内。不能旋转、缩放或重绘位图。
- **R2 — 对齐标记。** 创建并返回一个 `SpawningPoints` 子对象，其中包含 `SpawnTop` 和 `SpawnBot`。在精灵平移后，将两者对齐上方和下方尖刺尖端，误差在 2 个图像空间像素内。坐标通过容器相对于陷阱，而不是相对于已平移的精灵。
- **R3 — 层级与继承。** SpawnTop 的 `z = 0`，SpawnBot 的 `z = 1`。精灵和标记层级均需响应父级变换。层级 0.5 的探测遮挡物盖住 SpawnTop，但不能盖住 SpawnBot。
- **R4 — 配套环境。** 保留 Move parent、Rotate parent、Toggle layer probe 和 Reset。根对象初始位于 [300, 190]，移动增加 [40, 20]，旋转增加 90 度。重置恢复居中的主体和两个对齐标记，不得重复创建，并关闭探测遮挡物。

验收分别检查主体居中、平移后的尖端坐标、层级、位图/旋转不变、父级变换、实际可见绘制顺序和重置。公开示例移动父级。不得修改检查或伪造结果。
