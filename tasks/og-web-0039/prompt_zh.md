# 构建使用分列统计的音频目录浏览器

补全 `component.js` 中的 `createDemo(host,{manager,listFiles,soundDir='assets'})`。返回一个对象，公开配置的目录、`update()` 方法和 `dispose()` 方法。所提供的八声部音频管理器、真实媒体解码、动画帧更新及声音输出已经可用。

- **R1 — 全屏布局。** 使提供的容器填满视口，四边均保留 20 像素内边距。居中放置恰有 2 列的网格，水平和垂直间距均为 10 像素。视口变化时布局仍应居中。
- **R2 — 发现音频按钮。** 调用 `listFiles(soundDir)`，为每个以 .wav 或 .ogg 结尾的返回文件名创建一个按钮，忽略其他文件。按钮显示完整文件名，按下时用带目录的路径调用 `manager.play(path)`。支持不同目录，避免重复路径分隔符。使用实际提供的音频文件。
- **R3 — 顶部分列统计。** 在视口顶部添加水平栏。子项依次为：`Available Streams:` 标签、可用数标签、垂直分隔线、`Queue:` 标签、排队数标签。四个标签均使用提供的 `Poppins` 字体，字号为 24 像素。音频按钮使用相同字体。分隔线必须可见。
- **R4 — 实时数量。** 每次更新都将 `manager.available.length` 和 `manager.queue.length` 显示在对应标签中。不能根据点击次数或另外模拟的池推算数量。初始数量应反映管理器当前状态；提供的管理器初始有 8 个可用声部，队列为空。
- **R5 — 生命周期。** 清理时移除此组件的监听器和内容，重复清理安全。重置后每个音频文件恰有一个按钮，每次按下恰好调用一次播放。保留提供的停止音频、重置、声部指示及实际输出电平表。

按钮网格使用 `#sound-grid`，统计栏使用 `#counts`。统计栏子项为 `#available-label`、`#available-count`、`#separator`、`#queue-label`、`#queue-count`；分隔线具有分隔线角色。由于这是静态浏览器应用，所提供的目录服务读取本地文件清单。验收注入不同目录和管理器，检查布局及字体加载，播放真实解码的源音频，观察自然播放完成，并检查全部 8 个声部和排队请求。保持页面可通过 `index.html` 运行。
