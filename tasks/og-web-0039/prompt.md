# Build an audio directory browser with separate statistics

Complete `createDemo(host,{manager,listFiles,soundDir='assets'})` in `component.js`. Return an object exposing the configured directory, an `update()` method and a `dispose()` method. The supplied eight-voice audio manager, real media decoding, animation-frame updates and sound output already work.

- **R1 — Full-screen layout.** Fill the viewport with the provided host and use 20 pixels of padding on every side. Center a grid with exactly 2 columns and 10-pixel horizontal and vertical gaps. Keep the layout centered as the viewport changes.
- **R2 — Discover sound buttons.** Call `listFiles(soundDir)` and create one button for every returned filename ending in .wav or .ogg. Ignore other files. Each button displays the complete filename and calls `manager.play(path)` with its directory-qualified path when pressed. Support a different directory and avoid duplicate path separators. Use the actual supplied audio files.
- **R3 — Separate top-bar statistics.** Add a horizontal bar at the top of the viewport. Its children, in order, are: label `Available Streams:`, available-count label, vertical separator, label `Queue:`, queue-count label. Use the supplied `Poppins` font at 24 pixels for all four labels. Use the same font for sound buttons. The separator must be visible.
- **R4 — Live counts.** Each update displays `manager.available.length` and `manager.queue.length` in their respective labels. Do not infer counts from clicks or from a separate simulated pool. Initial counts reflect the manager's current state; the supplied manager starts with 8 available voices and an empty queue.
- **R5 — Lifecycle.** Dispose removes this component's listeners and content; repeated disposal is safe. Reset must rebuild exactly one button per audio file, with one play call per press. Preserve the supplied Stop audio, Reset, voice indicators and actual output meter.

Use `#sound-grid` for the button grid and `#counts` for the statistics bar. Its children are `#available-label`, `#available-count`, `#separator`, `#queue-label` and `#queue-count`; the separator has the separator role. The supplied directory service reads local file manifests because this is a static browser application. Acceptance injects a different directory and manager, checks layout/font loading, plays decoded source audio, observes natural completion and tests all 8 voices plus queued requests. Keep the page runnable through `index.html`.
