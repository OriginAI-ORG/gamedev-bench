# Assemble the viewport menus

Complete `component.js` in the supplied local browser scene in `game/`; retain `index.html`. The MenuHandler, transition material, game loop and inspection controls are supplied. Build the menu component and connect its references and callbacks.

- **R1 — Component.** Export `createMenus(host, {MenuHandler, material, game, actions})`. Append a viewport-filling root with id menus to host and construct the supplied MenuHandler with that root, game and actions. Return that handler, named Menus. The component must remain interactive and animate while gameplay is paused. Keep its transparent root from blocking unrelated controls.
- **R2 — Panels and layout.** Create launch-menu, pause-menu and restart-menu sections, all hidden before the handler starts. Anchor each panel at the viewport midpoint with left offset -205 and top offset -196 CSS pixels. Their right/bottom offsets are respectively [205, 196], [205, 45] and [205, 63], yielding sizes 410×392, 410×241 and 410×259. Preserve these offsets when resizing. Each panel contains a vertically stacked column filling its inset content area. The launch labels read FPS Horror and By Bonkahe; the other titles read Paused and You Died.
- **R3 — Buttons.** Use real buttons with a 31-pixel font. Launch has Full Screen Toggle, Play and Quit; Pause has Resume and Quit; Restart has Restart and Quit. Use `data-action` values fullscreen, play, resume, restart and quit. Connect them respectively to the returned handler's `toggleFullScreen`, `beginLaunch`, `hidePauseMenu`, `restartLevel` and `exitGame` methods. Every Quit button calls exitGame. Do not replace the supplied methods with local status labels.
- **R4 — References and overlay.** Assign the exact panels to `launchMenu`, `pauseMenu` and `deathMenu`. Create transition-overlay covering the viewport, with `z-index: 2` and `pointer-events: none`. Assign the provided material itself to `transitionMaterial` and call `material.attach(overlay)` so the handler and rendered overlay share one material.
- **R5 — Runtime integration.** Preserve the supplied start behavior: show Launch, hide the other panels and pause gameplay; the overlay fades over 2 seconds while paused. Play hides Launch, transitions in over 2 seconds, resumes the game and fades out. Pause freezes the visible moving actor/time; Resume works while paused. Show death exposes Restart; Restart creates a fresh session. Full Screen Toggle enters/exits browser fullscreen from the user gesture. Quit performs its transition and ends the local session with Session ended. Preserve Reset and the inspection toolbar.

Acceptance checks hidden initial construction, panel bounds at multiple viewport sizes, labels, typography, every callback and exact reference, viewport overlay and click-through, real paused/resumed motion, fullscreen and restart/quit. The public example checks the initial Launch menu. Do not modify checks or fabricate results.
