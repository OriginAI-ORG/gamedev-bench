# 为嵌套的目标查找器绑定单位

已完成的目标查找器是检测器的子对象，并从该父对象读取检测事件，但它缺少角色引用。

- **R1 — 绑定角色。** 补全 `bindings.js` 中的 `bind(unit, config)`，使 `unit.targetFinder.actor` 引用单位。保持 `TargetFinder` 位于 `DetectRange` 内、与 `Collider` 同级，并保留单位的 `detectRange`、`targetFinder` 引用和属性转发。
- **R2 — 保留检测和选敌。** 保持队伍 0 以 enemy_units 为目标、队伍 1 以 player_units 为目标，基础范围 36、玩家攻击范围 2、半径 72、24 乘 24 的单位碰撞体及提供的碰撞位。父检测器事件必须更新具有类型过滤的范围数组并通知变化。全局最近目标选择仍独立于范围数组。
- **R3 — 实时行为。** 初始只有 (50,0) 处单位在范围内，(130,0) 处单位在范围外。将远处单位移至 (10,0) 后选择它。把两者移至 (300,0) 后清空范围列表。保留控件、渲染、重复属性赋值和监听清理。

只修改 `bindings.js`，其余提供的文件保持不变。提交以 `index.html` 为入口的完整包。验收检查嵌套结构、对象身份、来自父对象的事件、双方队伍、实际重叠、最近目标和清理。
