# 添加角色与武器的动作时间轴

补全 `component.js` 中的 `configureAnimations(player,{Clip})`，并返回同一个角色。所提供的角色包含 `character`、`knife`、`animator`、可用的 `onActionComplete` 回调和 `RESET` 片段。向 `player.animator.clips` 添加缺少的片段。

- **R1 — 受伤。** 添加 `hurt`，时长 0.3 秒，步长 0.1 秒，不循环。分别为原有 `player.character` 和 `player.knife` 对象添加 `frame` 轨道。两者均在 0、0.1、0.2 秒使用第 70、71、72 帧。
- **R2 — 完成方法。** 在 0.3 秒添加方法事件，目标是角色自身，调用 `onActionComplete`。每次受伤播放完成只调用一次，包括时钟单步跨越结束点的情况。随后保持第 72 帧。重新开始受伤播放后允许产生一次新的完成调用。
- **R3 — 下落与倒地。** 添加 `fall` 和 `grounded`，均循环播放，时长和步长为 0.1 秒。各自包含两条轨道，指向同一对精灵的 `frame` 属性。下落在时间 0 使用第 80 帧，倒地在时间 0 使用第 82 帧。两者都不调用完成方法。
- **R4 — 保留结构。** 保留所提供的 `RESET` 片段及其对象身份。保留两张 480×480 图集、10×10 单元、关闭居中和 [-24,-48] 偏移。不要替换任何精灵或播放器。两张图像都必须参与绘制。
- **R5 — 播放与重置。** 保留动作按钮、播放/暂停、0.05 秒单步和重置。实际图像必须遵循时间轴。重置恢复初始姿态并清空显示的完成次数。

所提供的 `Clip` 接受 `duration`、`step`、`loop`、`tracks` 和 `events`。轨道包含 `target`、`property`，以及由 [时间,值] 对组成的 `keys`。方法事件包含 `at`、`target` 和 `method`。验收检查双轨道、精确时间、实际回调调用、重复播放、源图像及实际绘制的裁剪。保持本地页面可通过 `index.html` 运行。
