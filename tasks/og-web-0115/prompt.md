# Place tight circular highlights on six collectibles

Inspect the original `assets/platformer.jpg` image and complete `overlays.json`. The supplied SVG renderer loads the scene transform from `level.json`; keep that file, the image and the supplied runtime unchanged. Shape placement is the task, so determine the target positions by inspecting the image.

- **R1 — Coordinate hierarchy.** Keep the `Level` transform and the image's top-left origin from level.json. Add the `CoinHighlights` group beneath Level, alongside the original image. All highlight geometry must inherit the same parent translation, scale and rotation as the image.
- **R2 — Separate shapes.** Create exactly 6 independently rendered polygons named `CoinHighlight1` through `CoinHighlight6`. Each polygon has at least 8 vertices and forms a tight circular outline around one yellow star coin. Cover every coin once; the numbering may use any one-to-one assignment.
- **R3 — Tight coverage.** Each circle must closely cover its coin with minimal spill. Acceptance requires intersection-over-union of at least 0.90 against the corresponding annotated circular target in image-local coordinates. It accounts for the highlight's own transforms and the containing group's transform; duplicate coverage of one target does not satisfy another.
- **R4 — Semi-transparent appearance.** Give every polygon a visible fill with effective alpha strictly between 0 and 1. Preserve the original image beneath it. The image must not be repainted or replaced with a precomposited screenshot.
- **R5 — Inspectable result.** Preserve Show highlights and Reset view so the original and composited image can be compared. All six overlays must visibly affect their target regions and remain aligned when inherited transforms are applied.

The overlay document has `name`, optional `position`, `scale`, `rotation`, and a `children` array. Each child has `name`, `points` as [x,y] vertices, `color` as normalized [red,green,blue,alpha], and optional position, scale, rotation and `modulate`. Defaults are position [0,0], scale [1,1], rotation 0 radians and modulation [1,1,1,1]. Effective color multiplies color and modulation componentwise. The provided renderer handles all transforms and drawing. Acceptance checks original assets, hierarchy, geometry, transparency and rendered pixels; it does not require an exact vertex list. Keep `index.html` runnable.
