# Add textured smoke ribbons above the campfire

Implement `configure(scene, target)` in `configure.js`. The scene already contains a campfire base and a working flame. Browser particle simulation, curve sampling and textured WebGL ribbon rendering are provided. `requirements.json` supplies this task's distinct values as `target`.

- **R1 — Add the emitter.** Add one `SmokeEmitter` named `SmokeStylized` as a child of `scene.campfire`, at local [0, 0], and assign it to `scene.smoke`. Bind `assets/smokelet.png`. Set `amount`, `lifetime` and `preprocess` to their target values. Preserve the existing campfire position [600, 500], `CampfireBase`, `Fire`, their textures and all supplied flame settings.
- **R2 — Configure motion.** Give the emitter its own `SmokeMaterial`. Set direction to [target wind, -1], initial `velocity` to the target range, gravity to [0, 0] and `directionalVelocity` to [-target sway, target sway]. Supply a `CurveXYZ` as `directionalCurve`. Its X `Curve` must have at least 3 ordered control points over normalized age 0 to 1 and both positive and negative values within [-1, 1], producing visible sideways sway. Keep Y and Z zero. The provided runtime normalizes initial direction and integrates the X curve as horizontal velocity modulation.
- **R3 — Grow and fade.** Set `scaleMax` from the target and assign a `scaleCurve` with nondecreasing values from 0 at age 0 to 1 at age 1, so width grows from its initial size to the target multiple. Assign a `Gradient` as `colorRamp`, with at least 3 ordered stops: orange near the flame, a gray middle stop, and a fully transparent final stop. Use normalized RGBA values in [0, 1]. Choose the curve shape and colors while preserving these constraints.
- **R4 — Continuous trails.** Enable `trails`, with `trailLifetime`, `sections` and `subdivisions` from the target. The runtime retains the configured duration of each particle's trajectory and samples sections times subdivisions plus 1 points to form a textured ribbon. Those settings must drive real trails, changing width and color along the motion history. Preprocessing must show filled trails on first display.
- **R5 — Preserve the package.** Use independent material, curve, gradient and range objects for each configured scene. Keep the original three image files, existing simulation/renderer and the pause/run, 0.1 second step and repeatable reset controls. Only edit `configure.js`; submit the complete package with `index.html` as entry.

Acceptance checks hierarchy, exact task values, actual texture bindings, curve and gradient semantics, motion/growth/fade samples, trail duration and tessellation, preheated state and rendered changes. The provided runtime owns particle simulation; the task is to assemble and configure the effect.
