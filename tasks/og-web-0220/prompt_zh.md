# 为营火添加带纹理的烟带

实现 `configure.js` 中的 `configure(scene, target)`。场景已经包含营火底座和可工作的火焰。浏览器粒子模拟、曲线采样和带纹理的 WebGL 烟带绘制已经提供。`requirements.json` 以 `target` 给出本题的不同参数值。

- **R1 — 添加发射器。** 在 `scene.campfire` 下添加一个名为 `SmokeStylized` 的 `SmokeEmitter`，局部位置为 [0, 0]，并赋值给 `scene.smoke`。绑定 `assets/smokelet.png`。将 `amount`、`lifetime` 和 `preprocess` 设为目标值。保留现有营火位置 [600, 500]、`CampfireBase`、`Fire`、它们的纹理和所有提供的火焰设置。
- **R2 — 配置运动。** 为发射器设置独立的 `SmokeMaterial`。方向为 [目标风向值, -1]，初始 `velocity` 为目标范围，重力为 [0, 0]，`directionalVelocity` 为 [-目标摆动值, 目标摆动值]。使用 `CurveXYZ` 作为 `directionalCurve`。其 X `Curve` 在归一化年龄 0 到 1 内至少有 3 个有序控制点，值位于 [-1, 1]，且同时有正值和负值，以产生可见的横向摆动。Y 和 Z 保持为零。提供的运行库会归一化初始方向，并将 X 曲线作为水平速度调制进行积分。
- **R3 — 增宽与淡出。** 根据目标设置 `scaleMax`，并赋予 `scaleCurve`，其值从年龄 0 时的 0 非递减地增加到年龄 1 时的 1，让宽度从初始大小增长到目标倍数。使用 `Gradient` 作为 `colorRamp`，至少有 3 个有序色标：靠近火焰处为橙色，中间色标为灰色，最后一个色标完全透明。使用 [0, 1] 内的归一化 RGBA 值。在这些约束内自行选择曲线形状和颜色。
- **R4 — 连续拖尾。** 启用 `trails`，并根据目标设置 `trailLifetime`、`sections` 和 `subdivisions`。运行库保留每个粒子配置时长的运动轨迹，并以段数乘细分数加 1 个点采样成带纹理的烟带。这些设置必须驱动真实拖尾，使宽度和颜色沿运动历史变化。预热必须让初次显示时就有完整拖尾。
- **R5 — 保留文件包。** 每次配置场景都使用独立的材质、曲线、渐变和范围对象。保留原始三张图像、现有模拟与绘制程序，以及暂停/运行、0.1 秒步进和可重复重置控件。只修改 `configure.js`；提交完整文件包，以 `index.html` 为入口。

验收检查层级、逐题精确参数、实际纹理绑定、曲线与渐变语义、运动/增宽/淡出采样、拖尾时长和细分、预热状态以及绘制变化。提供的运行库负责粒子模拟；本题的工作是组装与配置特效。
