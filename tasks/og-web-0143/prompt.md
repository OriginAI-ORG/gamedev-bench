# Smooth obstacle-aware pursuit

Complete the browser game's missing pursuit component. The supplied tile renderer, collision service and path planner already implement the level; your work is controller behavior and component assembly.

- **R1 — Assembly.** In `setup.js`, attach a `Navigation` child to the actor, with an `Agent` and a `Timer` as children. Use the provided services. Construct `Controller`, bind its configured target property to the live object named by `config.target` in `objects`, and connect timer timeout events to `onTimer()`. Return the components and a `dispose()` function that disconnects the listener and stops the timer.
- **R2 — Continuous motion.** Complete `physics(dt)` in `controller.js`. Query `nextPathPosition()` every physics step. Normalize the vector from the body's current global position to that waypoint, using a zero vector for zero length. Interpolate each velocity component toward direction times `speed` with weight `acceleration * dt`, then call `moveAndSlide(dt)`. Preserve the supplied defaults: speed 300 and acceleration 7. Read their current values each step.
- **R3 — Live target refresh.** The timer starts automatically and fires every 0.1 seconds. `onTimer()` copies the bound object's current global position to `agent.targetPosition`; a missing target does nothing. Repeated target movement and inherited parent offsets must be reflected. Keep an object reference, not an initial position snapshot or name string.
- **R4 — Level integration.** Preserve the supplied 101 fence cells, 720 terrain cells, 32-pixel tiles, images and camera. The actor starts at (317,246), the target at (610,250). Keep the actor's radius 12, collision layer 2, mask 1, floating motion and zero minimum wall-slide angle. Follow the supplied traversable route continuously without entering a wall, and approach a reachable stationary target to within 20 pixels after 30 simulated seconds.
- **R5 — Browser interaction.** Keep the supplied canvas, run/pause, 0.1-second step, 10-second advance and reset controls. Clicking free space moves the target; clicking a wall is ignored. Pursuit must respond to target changes while running. Reset restores the scene. Rendering must reflect actual body positions.

Edit only `controller.js` and `setup.js`. Keep all other supplied files unchanged. Submit the complete browser package with `index.html` as its entry. Public feedback checks visible movement; private acceptance also checks velocity math, timer cadence, object identity, cleanup, collision-free trajectories and retargeting. The path planner is provided and does not need to be reimplemented.
