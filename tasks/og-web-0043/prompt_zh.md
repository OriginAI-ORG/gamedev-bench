# 生命与分数状态栏

为从 `index.html` 启动的浏览器游戏，在 `game/view.js` 中建立状态栏。全部依赖必须在本地。

- **R1 — 组件。** 导出 `mountHud(host, config, actions)`，返回 `render(state)`、`setMinimum(value)` 和 `dispose()`。将 UI 放在 `host` 内，独立于世界图层。此布局允许 `setMinimum` 不执行操作。
- **R2 — 边距。** 将 `#hud` 放在 `#scene` 顶部，左、上、右间距均恰好为 20 像素。调整游戏区尺寸时，宽度随之变化。
- **R3 — 读数。** 创建一个横向行，包含初始为 `Health: 100` 的 `#life` 和初始为 `Score: 0` 的 `#score`。分数位于该行右边，文字右对齐。根据 `state.life` 和 `state.score` 渲染，不得重复创建标签。
- **R4 — 集成。** 保留提供的命中、受伤、平移和重置控件。状态变化必须更新可见标签，重置恢复初始值。平移世界时 HUD 几何必须保持不变。
- **R5 — 范围。** 在 1100×760 和 520×800 下保持状态行可读。游戏结束覆盖层或燃料仪表不属于必做内容，且不得遮挡状态行。

验收检查精确边距、响应式宽度、右对齐、初始及变化后的值、与世界平移的独立性以及重置。公开示例将 Score: 0 改为 Score: 100。不得修改检查或伪造结果。
