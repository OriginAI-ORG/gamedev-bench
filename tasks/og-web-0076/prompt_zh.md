# 将 Julia 材质绑定到全视口面板

补全 `component.js` 中的 `createPanel(root,{TexturePanel,material,texture})`，并更新 `material.json`。所提供的 WebGL 绘制器和 `julia.frag` 已实现图像效果。配置面板和材质，不修改该着色器或所提供的绘制服务。

- **R1 — 面板组装。** 创建 `TexturePanel`，将其 `element` 添加到所提供的根容器，并返回面板。将 `anchors` 设为 [0,0,1,1]，`offsets` 设为 [0,0,0,0]，无边缘偏移地填满视口。
- **R2 — 准确资源绑定。** 将提供的材质对象赋给面板的 `material`，将提供的图像对象赋给其 `texture`，保留两者对象身份。图像为所提供的 `icon.png`，材质使用 `julia.frag`。不要用无关资源或预先绘制的图片替代。
- **R3 — 材质种子。** 仅将 `material.json` 中材质的 `seed` 值改为 [0.40,-0.20]。其余全部材质参数和着色器源码保持不变，包括着色器默认种子 [-0.794084,0.136444]。材质覆盖值必须驱动实际绘制输出。
- **R4 — 扩展与尺寸调整。** 将 `growX` 和 `growY` 设为 `both`，跟随视口尺寸变化。最小宽度或高度超过已分配尺寸时，所提供的布局服务必须沿该轴向两个方向等量扩展面板。
- **R5 — 可用预览。** 保留最小宽度/高度控件及重置尺寸。使用提供的着色器和图像资源，在整个面板上绘制实际材质。重置尺寸恢复填满视口。

纹理面板、着色器编译、绘制和布局计算均已提供。验收检查资源身份、材质文件、不变的着色器字节、独立分形像素计算、变化后的 uniform 参数、尺寸调整及居中的最小尺寸扩展。保持页面可通过 `index.html` 运行。
