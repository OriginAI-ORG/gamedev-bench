# 组装棋盘式游戏区域和备战席

在 `tileset.json` 中创建共享资源，在 `scene.json` 中创建图层结构。浏览器加载器、图集绘制器、父级变换和可见性控件均已提供。直接编写场景数据。

- **R1 — 共享瓦片集。** 使用提供的 `tiles.png` 图集，瓦片大小为 [32,32]，间隔为 [0,0]。包括空高亮层在内的每个图层都引用同一个 `tileset.json` 资源，并解析为同一对象。保留源图像，使用有效图集坐标。
- **R2 — 游戏区域。** 添加名为 `GameArea` 的根级子图层，位置为 [160,32]。至少用两种不同图集瓦片绘制完全填满的棋盘式矩形区域，至少有 2 列、2 行。水平或垂直相邻单元必须使用不同瓦片，不能有空洞或重复坐标。
- **R3 — 游戏区域子层。** 在 GameArea 下添加 `Decor` 和 `Highlight` 子图层，局部位置均为 [0,0]。Decor 至少绘制一个单元，Highlight 保持完全为空。保留父子关系，使它们继承游戏区域的偏移。
- **R4 — 备战席及高亮层。** 添加独立的根级子图层 `Bench`，位置为 [160,320]，并至少绘制一个单元。为其添加自身的 `Highlight` 子图层，局部位置为 [160,32]，保持为空。因此，该高亮层全局位置为 [320,352]。两个高亮层是不同对象。
- **R5 — 可见组合。** 根据层次和偏移绘制实际图集单元。保留各图层可见性复选框及重置可见性。空高亮层保持配置和可检查状态，不绘制占位单元。

组使用 `name` 和 `children`。每个图层的 `type` 设为 `layer`，并包含 `name`、`position`、`tileset`、`cells` 及可选的 `children`。单元为 [列,行,图集列,图集行]。瓦片集使用 `src`、`tileSize` 和 `separation`。验收检查共享资源、交替排列的游戏区域、有内容的装饰层/备战席、空高亮层、局部/全局位置和实际绘制裁剪。保持页面可通过 `index.html` 运行。
