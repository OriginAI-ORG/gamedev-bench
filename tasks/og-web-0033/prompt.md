# Draggable star decoration

Complete `draggable.js` in the supplied local browser game in `game/`; retain `index.html`. The fixture supplies a 1024×520 game area, `star.svg`, target rectangles and frame updates.

- **R1 — Component.** Export `Draggable extends EventTarget`, constructed with `(host, {position, scale = [1, 1], targets})`. Save independent copies as `initialPosition` and `initialScale`; maintain `.position`, `.element` and `.destroyed`. Use a 72×72 collision rectangle, `collisionMask = 2` and `damping = 20`. Render one `.draggable` with a loaded `.decoration` image uniformly scaled to 0.58.
- **R2 — Motion.** Left pointer press begins dragging; captured movement updates the destination. In `update(delta)` smoothly approach the pointer with factor `1 - exp(-20 * delta)` on each coordinate, rather than teleporting. Expose `beginDrag()`, `movePointer({x, y})`, `release()` and `cancelDrag()` for the same behavior. Store the drag-start position. Escape or pointer cancellation restores it and prevents a later release from dropping or destroying the object.
- **R3 — Drop contract.** Release ends dragging and emits one `dropped` CustomEvent with `detail: {draggable, overlaps}`. Include this exact component and the exact overlapping target objects after filtering their `.layer` by the collision mask. Test rectangle overlap at the decoration's current position, not just its center or the pointer. If no overlapping target has `id === 'DropTarget'`, call `selfDestruct()`; otherwise retain the decoration. Repeated release while idle does nothing.
- **R4 — Animation.** `playSpawnAnimation()` grows the root from zero to its captured initial scale over 160 ms. `selfDestruct()` shrinks from its current scale to zero over 160 ms and then removes the element and input subscriptions. Neither operation may be an immediate appearance/removal. The sprite's own 0.58 scale remains separate. `dispose()` safely removes an instance immediately for reset.
- **R5 — Fixture.** Initial position is (512, 360); DropTarget is centered at (512, 180), size 120×48, layer 2. The orange layer-4 decoy is filtered. Preserve Reset, live count and the drop payload display. Reset restores one fresh decoration and clears the log.

Acceptance checks initial copies, scaled sprite and collision geometry, timed spawn/shrink, smooth frame-rate-independent motion, pointer input and cancellation, exact event payload identities, edge overlap, masks, valid/invalid drops and reset. The public example drops into the green region. Do not modify checks or fabricate results.
