# 为六个收集物放置紧贴的圆形高亮

查看原始 `assets/platformer.jpg` 图像，并完成 `overlays.json`。提供的 SVG 绘制器从 `level.json` 加载场景变换；保持该文件、图像和提供的运行代码不变。本题考查形状放置，请通过观察图像确定目标位置。

- **R1 — 坐标层次。** 保留 level.json 中的 `Level` 变换和图像左上角原点。在 Level 下添加 `CoinHighlights` 组，与原图像同级。所有高亮几何必须与图像继承相同的父级平移、缩放和旋转。
- **R2 — 独立形状。** 创建恰好 6 个独立绘制的多边形，命名为 `CoinHighlight1` 至 `CoinHighlight6`。每个至少有 8 个顶点，并在一个黄色星形金币周围形成紧贴的圆形轮廓。每个金币恰好覆盖一次；编号可采用任意一一对应方式。
- **R3 — 紧密覆盖。** 每个圆形必须紧贴金币，尽量减少溢出。验收要求其与图像局部坐标中对应圆形标注目标的交并比至少为 0.90。计算包含高亮自身变换和容器组变换；重复覆盖一个目标不能替代另一个目标。
- **R4 — 半透明外观。** 每个多边形都有可见填充，有效 alpha 严格介于 0 和 1 之间。保留下方原始图像，不得重绘图像或替换成预合成截图。
- **R5 — 可检查结果。** 保留显示高亮和重置视图控件，以便对比原图与叠加结果。六个高亮都必须在各自目标区域产生可见效果，并在应用继承变换后保持对齐。

覆盖文档包含 `name`、可选的 `position`、`scale`、`rotation`，以及 `children` 数组。每个子项包含 `name`、以 [x,y] 表示顶点的 `points`、归一化 [红,绿,蓝,alpha] 的 `color`，以及可选的位置、缩放、旋转和 `modulate`。默认位置 [0,0]、缩放 [1,1]、旋转 0 弧度、调制 [1,1,1,1]。有效颜色由颜色与调制逐分量相乘。提供的绘制器负责所有变换和绘制。验收检查原始素材、层次、几何、透明度和绘制像素，不要求完全相同的顶点列表。保持 `index.html` 可运行。
