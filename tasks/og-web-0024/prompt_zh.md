# 陷阱生成标记坐标

完成 `game/` 中配套本地浏览器场景的 `component.js`；保留 `index.html`。配套环境提供场景变换、陷阱位图和检查控件。

- **R1 — 层级。** 导出 `configureTrap(trap, Node)`。用配套场景对象构造函数，在 `trap` 下创建一个 `SpawningPoints` 子对象，其中恰好包含名为 `SpawnTop` 和 `SpawnBot` 的两个子对象。返回此容器。保留已有 `Sprite` 及其贴图/变换。
- **R2 — 坐标。** 局部坐标设为 `SpawnTop: [0, 15]` 和 `SpawnBot: [0, -15]`。这些名称用于标识规定坐标；此浏览器场景的 Y 正方向向下。SpawnTop 的 `z` 设为 0，SpawnBot 的 `z` 设为 1。
- **R3 — 继承与顺序。** 标记继承陷阱和父级变换，不能固定在屏幕坐标上。SpawnBot 必须绘制在中间层级 0.5 的探测遮挡物前，SpawnTop 绘制在其后。各标记保持挂在容器下。
- **R4 — 配套环境。** 保留 Move parent、Rotate parent、Toggle layer probe 和 Reset。根对象初始位于 [300, 190]，移动增加 [40, 20]，旋转增加 90 度。重置恢复原始场景，恰好两个标记，且探测遮挡物关闭。

验收检查准确层级和局部坐标、保留的精灵身份、变换后的实际渲染位置、位图可见性、绘制顺序和重置。公开示例移动父级并观察标记。不得修改检查或伪造结果。
