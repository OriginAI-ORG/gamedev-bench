# 用半透明多边形贴合星形收集物

查看原始 `assets/platformer_coins.jpg`，并完成 `overlays.json`。保留 `level.json` 中提供的场景配置、原始图像和浏览器绘制器。根据图像确定星星位置和轮廓，不要将场景替换成简化绘图。

- **R1 — 场景对齐。** 保留 level.json 中 `Level` 的位置、缩放和旋转，包括图像单独的局部偏移和左上角原点。`StarHighlights` 组保持在 Level 下，与图像同级，因此两者继承相同父级变换。
- **R2 — 星形轮廓。** 在 StarHighlights 下添加一个名为 `StarHighlight` 的多边形。使用至少 10 个顶点贴合图像顶部附近唯一的黄色星星，包括尖角和内凹角。多边形几何与原图像保持独立。
- **R3 — 覆盖率。** 紧密覆盖星星，尽量减少溢出。验收要求与 Level 局部坐标中的星形标注轮廓交并比至少为 0.85，计算包括多边形自身变换和容器组变换。使用像素中心采样，支持凹多边形，不要求完全相同的顶点列表。
- **R4 — 半透明。** 使用可见填充，有效 alpha 严格介于 0 和 1 之间。保留覆盖层下方的原场景，不得将图像替换成预合成截图。
- **R5 — 检查。** 保留显示高亮和重置视图控件。隐藏覆盖层后显示完整原图，重置后恢复对齐的覆盖层。显示时，多边形必须在星星区域产生可见效果。

覆盖文档使用 `name`、可选的 `position`、`scale`、`rotation`，以及 `children`。多边形包含 `name`、以 [x,y] 表示顶点的 `points` 和归一化 RGBA `color`，以及可选的位置、缩放、旋转和 `modulate`。默认位置 [0,0]、缩放 [1,1]、旋转 0 弧度、调制 [1,1,1,1]。有效颜色由颜色与调制逐分量相乘。绘制器提供层次、变换和绘制。验收检查原始素材、场景对齐、轮廓贴合、透明度和实际像素。保持 `index.html` 可运行。
