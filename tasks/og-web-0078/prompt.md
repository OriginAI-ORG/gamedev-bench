# Complete the minimap tracker in an integrated world

Complete the unfinished methods of `Minimap` in `component.js`. Its constructor, cached image references and world event wiring are already provided. The UI is [250,250] with a [200,200] grid. Keep the supplied UI, images, renderer and `world.js` unchanged.

- **R1 — State contract.** Preserve the constructor inputs `root`, optional `player`, `viewport` and `frame`, defaulting to the browser viewport and supplied `nextFrame`. Preserve `zoom` initially 1.5, `gridScale`, identity-keyed Map `markers`, cached `Grid`, `PlayerMarker`, `MobMarker`, `AlertMarker`, and `icons` keyed by `mob` and `alert`.
- **R2 — Deferred initialization.** `ready(objects)` awaits a frame before reading layout. Center the player marker at grid size / 2 and compute gridScale = grid size / (viewport size * zoom) componentwise. For every object's `groups` Set containing `minimap_objects`, duplicate the prototype chosen by `minimapIcon`, append the distinct clone under Grid, show it and record it by object identity. Preserve the hidden prototypes.
- **R3 — Projection.** `update()` returns without changes if no player exists. Otherwise rotate the centered arrow by player rotation + PI/2 radians. Project each object's `position` as (object position - player position) * gridScale + grid size / 2 componentwise. Use scale 1 inside [0,width) by [0,height); outside, use scale 0.75 and clamp coordinates to [0,grid size]. Restore scale 1 on reentry. Update actual image positions and transforms.
- **R4 — Zoom.** `setZoom(value)` and assignment to zoom clamp to [0.5,5] and immediately recompute gridScale. `onWheel(event)` adds 0.1 for negative `deltaY`, subtracts 0.1 for positive deltaY and ignores zero. Bind wheel events on the minimap, prevent page scrolling when handled, and refresh visible markers.
- **R5 — Removal and cleanup.** `removeObject(object)` removes the image and Map entry without affecting other markers or prototypes. Unknown or repeated removal is harmless. `dispose()` disconnects wheel handling and removes all clones; repeated disposal is harmless.
- **R6 — Preserve integration.** The supplied world assigns the player, gives objects their minimapIcon and group membership, and dispatches `removed` with `detail` equal to the removed object. Its existing listeners call removeObject. Keep W/S movement, A/D turning, Collect crate and Reset scene working with the completed tracker.

Acceptance checks a deferred layout frame, different viewport and grid sizes, equal-named distinct objects, all boundaries, both zoom limits, property assignment, real wheel input and the existing removal events. Keep `index.html` runnable.
