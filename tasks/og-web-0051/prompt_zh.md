# 将碰撞矩形贴合角色脚部

完成 `game/` 中配套浏览器场景的 `component.js`；保留 `index.html`。题包已提供玩家、浮动模式、完整 idle/walk 动画片段和方向映射。本题只需观察角色图像，添加缺失的碰撞矩形。

- **R1 — 保留已有组件。** 导出 `configurePlayer(player, services)`，修改并返回同一玩家。保持配套精灵、其动画对象及帧资源不变。保留默认 `idle0`、第 0 帧、`speedScale = 2` 和已有浮动模式。
- **R2 — 视觉贴合。** 添加配套 RectangleCollider。观察 idle0 的第 0 帧，将矩形放在两只可见脚部周围。高度应仅足以覆盖脚部，宽度大致等于头部宽度。坐标以完整未裁剪图像中心为基准，Y 正方向向下。不得将碰撞体放在躯干中心，也不得使用整张图像边界。
- **R3 — 功能边界。** 同一碰撞体必须同时驱动可见矩形和指针命中检测。脚部点应在框内，躯干中心点应在框外。切换预览方向或动画时保持碰撞体位置/尺寸。
- **R4 — 配套环境。** 保留实际位图预览及全部配套片段、方向控件、Idle/Run、Pause / Play、Advance 0.1 s、Probe pointer 和 Reset。初始暂停在 idle0/第 0 帧。重置在新玩家实例中恢复贴合的碰撞体和原有配套动画对象。保留美术署名和授权文件。

验收检查配套资源保留、碰撞体类型、相对可见脚部/头部的位置和近似尺寸、实际命中边界、对应屏幕矩形、未改变的动画渲染及重置。公开示例探测脚部。不得修改检查或伪造结果。
