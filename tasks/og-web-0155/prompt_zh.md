# 修复现有坦克 HUD 的连接

这个浏览器游戏已经包含可用的 HUD、拾取物和武器组件，但游戏包装层缺少对象绑定和事件订阅。修复 `wiring.js`，同时保留提供的实现。

- **R1 — 绑定场景。** 在 `createGame(root, config)` 中保留现有的 `World`、`Tank` 和 `UI` 子对象，将 `hero_tank` 绑定到实际坦克，将 `scoreboard` 绑定到实际 HUD。保留启动分数 0 和装填值 1。
- **R2 — 分数连接。** 订阅坦克的 `pickup-collected` 事件。将事件详情中的分值加到游戏分数，并调用 HUD 的 `setScore`。提供的拾取物每个值 60 分；新生成的拾取物必须通过坦克事件工作，无需逐个向 HUD 注册。
- **R3 — 装填连接。** 订阅武器的 `reload-progress` 和 `reload-finished` 事件。将进度传给 `setReload`；完成事件独立将其设为 1。保留提供的 0.5 秒装填、0.2 量化步长、0 到 1 的范围、从下向上的纹理填充、初始满值和开火锁定。两层图像均保持取自 `assets/ammo_ui_icon.png`，显示尺寸使用提供的 32 乘 48。
- **R4 — 集成与清理。** 保留 W/S 驾驶、A/D 转向、Q/E 旋转炮塔、空格或 Fire 开火、暂停、0.1 秒推进和重置。打破箱子产生拾取物；驾驶经过拾取物后通过事件更新分数。`dispose()` 必须断开所有游戏订阅，并且能够安全重复调用。重置恢复分数 0、满装填指示器和一组事件连接。

只修改 `wiring.js`，其余提供的文件保持不变。提交以 `index.html` 为入口的完整包。验收测试实际游玩、独立于演示控件的事件投递、正确的对象身份、进度渲染和清理。组件实现已提供。
